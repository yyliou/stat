第3-1節：集中趨勢量數

統計量與母數

寬鬆地說，平均指的是分布的中心，或是最典型的情形。平均量數也稱為集中趨勢量數，包括平均數、中位數、眾數與中程數。

統計量與母數

  • 統計量是使用樣本的資料值所得到的特徵或測量值。
  • 母數是使用某個特定母體的全部資料值所得到的特徵或測量值。

一般四捨五入規則

在算出最後答案之前不要先四捨五入。在中間步驟四捨五入，往往會擴大計算結果與精確值之間的差距。

平均數

平均數又稱算術平均，是把所有資料值相加後，再除以資料值的總個數。

平均數

平均數是所有數值的總和除以數值的總個數。

樣本平均數以 \bar{X} 表示，是一個統計量： \bar{X} = \frac{X_1 + X_2 + \cdots + X_n}{n} = \frac{\Sigma X}{n}

母體平均數以 \mu 表示，是一個母數： \mu = \frac{X_1 + X_2 + \cdots + X_N}{N} = \frac{\Sigma X}{N}

平均數的四捨五入規則

平均數的四捨五入規則

平均數應比原始資料多保留一位小數。若原始資料為整數，平均數取到小數第一位；若資料到小數第一位，平均數取到小數第二位。

希臘字母代表母數，羅馬字母代表統計量。除非另有說明，都假設資料來自樣本。

分組資料的平均數

分組資料求平均數的程序，假設每一組中所有原始資料值的平均等於該組的組中點。

程序——求分組資料的平均數

  1. 製作表格，欄位為 A（組別）、B（次數 f）、C（組中點 X_m）、D（f \cdot X_m）。
  2. 求出各組的組中點，填入 C 欄。
  3. 將各組的次數乘以組中點，乘積填入 D 欄。
  4. 求 D 欄的總和。
  5. 以 D 欄總和除以次數總和。

\bar{X} = \frac{\Sigma f \cdot X_m}{n}

中位數

某篇報導指出大學教授的所得中位數為 82,974 美元：受訪教授中有一半所得高於此數，另一半低於此數。

資料陣列與中位數

當資料集由小到大排序後，稱為資料陣列。

中位數是資料陣列的中點，符號為 MD。

程序——求中位數

  1. 將資料值由小到大排列。
  2. 確定資料值的個數。
  3. 若 n 為奇數，取中間的資料值為中位數；若 n 為偶數，取中間兩個值的平均數。

眾數

第三個平均量數是眾數，有時被稱為最典型的情形。

眾數

在資料集中出現次數最多的值稱為眾數。

  • 單峰——只有一個值出現次數最多。
  • 雙峰——有兩個值出現次數並列最多，兩者都是眾數。
  • 多峰——有超過兩個值出現次數並列最多。
  • 無眾數——沒有任何資料值出現超過一次。

注意

當沒有任何值出現超過一次時，不要說眾數是 0。這樣說是錯的，因為在某些資料（例如溫度）中，0 可能是真實存在的數值。

詮釋

中程數

中程數

中程數定義為資料集中最小值與最大值之和除以 2，符號為 MR。

MR = \frac{\text{最小值} + \text{最大值}}{2}

中程數是對平均非常粗略的估計，且容易受到單一極高或極低值的影響。

加權平均數

有時資料集中各個數值的代表性並不相同，此時須求加權平均數。

加權平均數

求變數 X 的加權平均數時，將每個數值乘上其對應的權數，再把乘積之和除以權數之和。

\bar{X} = \frac{w_1 X_1 + w_2 X_2 + \cdots + w_n X_n}{w_1 + w_2 + \cdots + w_n} = \frac{\Sigma wX}{\Sigma w}

其中 w_1, w_2, \ldots, w_n 為權數，X_1, X_2, \ldots, X_n 為數值。

平均數與中位數的性質與用途

平均數

  1. 平均數使用資料的所有數值。
  2. 由同一母體重複抽樣時，平均數的變動小於中位數或眾數。
  3. 平均數用來計算其他統計量，例如變異數。
  4. 資料集的平均數是唯一的，且不一定是資料值之一。
  5. 若次數分配含有開放組，平均數無法計算。
  6. 平均數受離群值影響，在這類情況下可能不是合適的平均量數。

平均數與中位數的性質與用途

中位數

  1. 中位數用來找出資料集的中心或中間值。
  2. 當需要判斷資料值落在分布的上半部或下半部時，使用中位數。
  3. 中位數可用於開放組的分布。
  4. 中位數受極高或極低值的影響小於平均數。

眾數與中程數的性質與用途

眾數

  1. 想知道最典型的情形時使用眾數。
  2. 眾數是最容易計算的平均量數。
  3. 當資料為名目或類別尺度時（如宗教信仰、性別、政黨傾向），可以使用眾數。
  4. 眾數不一定唯一。一個資料集可能有多個眾數，也可能沒有眾數。

中程數

  1. 中程數容易計算。
  2. 中程數給出全距的中點。
  3. 中程數受資料集中極高或極低值的影響。

分布形狀

次數分配可以呈現許多形狀，最重要的三種是右偏、對稱與左偏（圖 3-1）。

三種分布形狀

  • 右偏（正偏）——多數資料值落在平均數左側、集中於低端，尾巴在右側。平均數在中位數右側，眾數在中位數左側。
  • 對稱——資料值平均分布於平均數兩側。當分布為單峰時，平均數、中位數與眾數相同，且位於分布中央。
  • 左偏（負偏）——多數資料值落在平均數右側、集中於高端，尾巴在左側。平均數在中位數左側，眾數在中位數右側。

偏態與平均量數的選擇

美國的所得分布是右偏的：多數所得集中在低端，少數高所得在右側形成尾巴。若大多數學生考試成績很高，分數的分布就是左偏。

注意

當分布極度偏斜時，平均數會被拉向尾巴，因此中位數比平均數更適合作為集中趨勢量數。極度偏斜的分布也會影響其他統計量。

為什麼離散程度很重要

只知道資料集的平均數並不足以完整描述資料。鞋店老闆即使知道男鞋的平均尺碼是 10 號，如果只進 10 號鞋，生意也做不久。

母體變異數與標準差

資料的變異來自每個資料值與平均數之間的距離，此距離稱為離差 X - \mu。由於離差之和恆為零，因此將離差平方。

母體變異數與標準差

母體變異數是各數值與平均數距離平方的平均：

\sigma^2 = \frac{\Sigma(X - \mu)^2}{N}

母體標準差是變異數的平方根：

\sigma = \sqrt{\sigma^2} = \sqrt{\frac{\Sigma(X - \mu)^2}{N}}

其中 X 為個別數值，\mu 為母體平均數，N 為母體大小。

計算程序與四捨五入規則

程序——母體變異數與標準差

  1. 求資料的平均數 \mu = \dfrac{\Sigma X}{N}。
  2. 求每個資料值的離差 X - \mu。
  3. 將每個離差平方 (X - \mu)^2。
  4. 求平方和 \Sigma(X - \mu)^2。
  5. 除以 N 得到變異數。
  6. 對變異數開平方根得到標準差。

標準差的四捨五入規則

最後答案應比原始資料多保留一位小數。

變異數與標準差的用途

四項用途

  1. 用來判斷資料的分散程度，也便於比較兩組以上資料何者較為分散。
  2. 用來判斷變數的一致性。在螺帽與螺栓的製造中，直徑的變異必須很小，否則零件無法組合。
  3. 用來判斷落在某個區間內的資料值個數——例如柴比雪夫定理指出，至少 75% 的資料值落在平均數上下 2 個標準差之內。
  4. 在推論統計中經常使用。

變異係數

當兩個樣本的測量單位相同時，可以直接比較標準差。若要比較兩個不同變數的標準差，則須使用變異係數。

變異係數

變異係數以 \text{CVar} 表示，是標準差除以平均數，結果以百分比表示。

\text{CVar} = \frac{s}{\bar{X}} \cdot 100\% \quad \text{（樣本）} \qquad \text{CVar} = \frac{\sigma}{\mu} \cdot 100\% \quad \text{（母體）}

全距經驗法則

全距經驗法則

標準差的粗略估計為

柴比雪夫定理

柴比雪夫定理

資料集中落在平均數上下 k 個標準差之內的比例至少為 1 - \dfrac{1}{k^2}，其中 k 為大於 1 的數（k 不一定是整數）。

  • 至少四分之三，即 75% 的資料值落在平均數上下 2 個標準差之內。
  • 至少九分之八，即 89% 的資料值落在平均數上下 3 個標準差之內。

此定理可適用於任何分布，不論其形狀為何。

經驗（常態）法則

經驗法則

當分布呈鐘形（常態）時：

  • 約 68% 的資料值落在平均數上下 1 個標準差之內。
  • 約 95% 的資料值落在平均數上下 2 個標準差之內。
  • 約 99.7% 的資料值落在平均數上下 3 個標準差之內。

由於經驗法則要求分布近似鐘形，其結果比適用於所有分布的柴比雪夫定理更為精確。

資料的線性轉換

有時必須把資料值轉換成另一種數值——例如把在加拿大收集的攝氏溫度換算成華氏，供美國的研究使用。這種改變稱為資料的線性轉換。

加上一個常數

當每個資料值都加上一個常數時，平均數增加該常數，而標準差不變。

乘以一個常數

當每個資料值都乘以一個常數時，新資料集的平均數等於該常數乘以原平均數，新資料集的標準差等於該常數的絕對值乘以原標準差。

第3-3節：位置量數

定位資料值在分布中的位置

除了集中趨勢量數與離散量數之外，還有位置量數。這些量數包括標準分數、百分位數、十分位數與四分位數，用來指出某個資料值在資料集中的相對位置。

若某個值位於第 80 百分位數，代表有 80% 的數值低於它、20% 的數值高於它。中位數就是對應第 50 百分位數的值。

標準分數

音樂測驗得 90 分與英文測驗得 45 分無法直接比較，因為兩份試卷的題數或每題配分未必相同。但可以利用平均數與標準差，做相對標準的比較。

z 分數（標準分數）

某數值的 z 分數（標準分數）是把該數值減去平均數後，再除以標準差：

z = \frac{\text{數值} - \text{平均數}}{\text{標準差}}

z = \frac{X - \bar{X}}{s} \quad \text{（樣本）} \qquad z = \frac{X - \mu}{\sigma} \quad \text{（母體）}

z 分數代表某個資料值高於或低於平均數幾個標準差。若 z > 0 表示高於平均數；z = 0 表示等於平均數；z < 0 表示低於平均數。

四分位數與十分位數

四分位數與十分位數

四分位數把分布分成四個相等的組，以 Q_1、Q_2、Q_3 表示。 十分位數把分布分成 10 組，以 D_1, D_2, \ldots, D_9 表示。

  • Q_1 = P_{25}，Q_2 = P_{50}，Q_3 = P_{75}
  • D_1 = P_{10}，D_2 = P_{20}，……，D_9 = P_{90}
  • 中位數等於 P_{50}、Q_2 或 D_5。

程序——求 Q_1、Q_2 與 Q_3

  1. 將資料由小到大排列。
  2. 求資料值的中位數，即為 Q_2。
  3. 求落在 Q_2 以下資料值的中位數，即為 Q_1。
  4. 求落在 Q_2 以上資料值的中位數，即為 Q_3。

離群值

離群值是與其他資料值相比極高或極低的資料值。

穩健與非穩健統計量

平均數與標準差會受離群值影響，因此稱為非穩健統計量；中位數與四分位距受離群值的影響較小，因此稱為穩健統計量。

辨識離群值

辨識離群值的程序

  1. 將資料由小到大排列，求 Q_1 與 Q_3。
  2. 求四分位距 \text{IQR} = Q_3 - Q_1。
  3. 把 IQR 乘以 1.5。
  4. 以 Q_1 減去步驟 3 所得的值，以 Q_3 加上該值。
  5. 檢查資料集中是否有小於 Q_1 - 1.5(\text{IQR}) 或大於 Q_3 + 1.5(\text{IQR}) 的數值。

注意

第3-4節：探索性資料分析

探索性資料分析

傳統分析的目的是確認對資料性質的各種推測；探索性資料分析的目的則是檢視資料，看看能從中發現什麼資訊，例如中心與分散程度。

探索性資料分析（EDA）

在探索性資料分析（EDA）中，資料可用莖葉圖整理。EDA 使用的集中趨勢量數是中位數，使用的離散量數是四分位距 Q_3 - Q_1，而資料以盒鬚圖（又稱箱形圖）呈現。

EDA 由 John Tukey 發展，並發表於他的著作 Exploratory Data Analysis（Addison-Wesley, 1977）。

五數綜合與盒鬚圖

五數綜合

盒鬚圖牽涉五個特定數值，合稱資料集的五數綜合：

  1. 資料集的最小值
  2. Q_1
  3. 中位數
  4. Q_3
  5. 資料集的最大值

盒鬚圖

盒鬚圖是這樣繪製的資料集圖形：從最小值畫一條水平線到 Q_1，從 Q_3 畫一條水平線到最大值，並畫一個左右兩邊分別通過 Q_1 與 Q_3 的盒子，盒內以一條垂直線通過中位數（即 Q_2）。

繪製盒鬚圖

程序——繪製盒鬚圖

  1. 求資料的五數綜合。
  2. 畫一條水平軸並標上刻度。刻度應由不大於最小值處開始，到不小於最大值處結束。
  3. 標出最小值、Q_1、中位數、Q_3 與最大值；畫出左右兩邊通過 Q_1 與 Q_3 的盒子；在中位數處畫一條垂直線；再從最小值畫線連到盒子左側、從最大值畫線連到盒子右側。

從盒鬚圖讀出的資訊

  1. 盒內的中位數
    1. 若中位數接近盒子中央，分布近似對稱。

    2. 若右側的線較長，分布為右偏。
    3. 若左側的線較長，分布為左偏。

樞紐值與四分位數

注意

在探索性資料分析中，繪製盒鬚圖用的是樞紐值（hinges）而非四分位數。當資料值個數為偶數時，樞紐值與四分位數相同；資料值個數為奇數時兩者略有差異。由於多數計算機與電腦程式使用四分位數，本書也採用四分位數。

也可以繪製修正盒鬚圖來檢查離群值：鬚只延伸到盒子外 1.5(\text{IQR}) 範圍內的最大值與最小值。

重要公式

集中趨勢

\bar{X} = \frac{\Sigma X}{n} \qquad \mu = \frac{\Sigma X}{N} \qquad \bar{X} = \frac{\Sigma f \cdot X_m}{n}

\bar{X} = \frac{\Sigma wX}{\Sigma w} \qquad MR = \frac{\text{最小值} + \text{最大值}}{2}

離散程度

R = \text{最大值} - \text{最小值} \qquad \sigma^2 = \frac{\Sigma(X-\mu)^2}{N} \qquad \sigma = \sqrt{\frac{\Sigma(X-\mu)^2}{N}}

s^2 = \frac{n(\Sigma X^2) - (\Sigma X)^2}{n(n-1)} \qquad s^2 = \frac{n(\Sigma f \cdot X_m^2) - (\Sigma f \cdot X_m)^2}{n(n-1)}

\text{CVar} = \frac{s}{\bar{X}} \cdot 100 \qquad s \approx \frac{\text{全距}}{4} \qquad 1 - \frac{1}{k^2}

重要公式

位置

z = \frac{X - \bar{X}}{s} \qquad z = \frac{X - \mu}{\sigma}

\text{累積百分比} = \frac{\text{累積次數}}{n} \cdot 100

\text{百分位數} = \frac{(\text{小於 } X \text{ 的數值個數}) + 0.5}{\text{數值總個數}} \cdot 100

c = \frac{n \cdot p}{100} \qquad \text{IQR} = Q_3 - Q_1

重點整理

重點

  • 集中趨勢量數——平均數、中位數、眾數與中程數；當各數值代表性不同時使用加權平均數
  • 平均數使用每一個數值，但會被離群值拉走；資料偏斜或含開放組時宜用中位數；名目資料唯一可用的平均量數是眾數
  • 分布形狀——右偏、對稱、左偏，平均數會被拉向尾巴
  • 離散量數——全距、變異數 \sigma^2 或 s^2、標準差 \sigma 或 s；樣本要除以 n-1 才是不偏估計
  • 變異係數可比較測量單位不同的變數之間的變異
  • 柴比雪夫定理適用於任何分布：至少 1 - 1/k^2 的數值落在平均數上下 k 個標準差之內；經驗法則（68-95-99.7%）適用於鐘形資料
  • 線性轉換——加上常數會平移平均數而標準差不變；乘以常數則兩者同時放大
  • 位置量數—— z 分數、百分位數、十分位數與四分位數，其中 Q_1 = P_{25}、Q_2 = P_{50} = MD、Q_3 = P_{75}
  • 離群值落在 Q_1 - 1.5(\text{IQR}) 之下或 Q_3 + 1.5(\text{IQR}) 之上；中位數與四分位距是穩健統計量，平均數與標準差是非穩健統計量
  • 探索性資料分析以五數綜合與盒鬚圖呈現資料的中心、分散程度與偏態
