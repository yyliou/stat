Overview

What Are Nonparametric Methods?

Standard parametric tests (z, t, F) require populations to be normally distributed. When this assumption cannot be met, nonparametric (distribution-free) methods provide valid alternatives.

They can also test hypotheses that do not involve specific population parameters like \mu, \sigma, or p.

Section 13-1: Advantages and Disadvantages of Nonparametric Methods

Advantages of Nonparametric Methods

Five Key Advantages

  1. Usable when the population is not normally distributed
  2. Applicable with nominal or ordinal data
  3. Can test hypotheses without specific population parameters
  4. Computations are often simpler than parametric alternatives
  5. Generally easy to understand and interpret

Disadvantages of Nonparametric Methods

Three Key Disadvantages

  1. Less sensitive than parametric counterparts when normality holds — larger differences are needed to reject H_0
  2. Use less information — e.g., the sign test only records whether values are above or below the median, not by how much
  3. Less efficient — larger sample sizes are needed; for example, the sign test is only ~60% as efficient as the z test

Basic Assumption

The sample(s) must be randomly selected. When two or more samples are used, they must be independent of each other (unless otherwise stated).

Ranking Data

How to Rank Data

Arrange values from lowest to highest, assigning ranks 1, 2, 3, …

Ties: When two or more values are equal, assign the average of the ranks they would have occupied.

Example: Values 3, 6, 6, 8, 10 - 3 → rank 1 - 6, 6 → tie for ranks 2 and 3 → each gets rank 2.5 - 8 → rank 4 - 10 → rank 5

Section 13-2: The Sign Test

The Sign Test: Overview

What Does the Sign Test Do?

The sign test tests the value of the median for a single sample, or compares two dependent samples (before vs. after).

Procedure for a single-sample test: - Compare each observation to the hypothesized median - Assign: + if above, - if below, 0 if equal - Test value = the smaller count of + or - signs - Use Table J (for n \leq 25) or the z approximation (for n \geq 26)

Sign Test: Critical Value and z Formula

Note

When n \leq 25 Use Table J with n = total + and - signs. Reject H_0 if test value \leq critical value.

When n \geq 26 — z Approximation z = \frac{(X + 0.5) - n/2}{\sqrt{n}/2}

where X = smaller count of + or - signs, n = sample size. Use Table E for critical values.

Example 13-1: Snow Cone Sales

Problem

A store owner hypothesizes that the median number of snow cones sold per day is 40. A sample of 20 days yields:

18, 43, 40, 16, 22, 30, 29, 32, 37, 36, 39, 34, 39, 45, 28, 36, 40, 34, 39, 52

At \alpha = 0.05, test the owner’s claim.

Example 13-1: Mathematical Solution

Solution

Step 1: H_0: MD = 40 (claim); H_1: MD \neq 40

Step 2: Compare each value to 40 and assign signs: -, +, 0, -, -, -, -, -, -, -, -, -, -, +, -, -, 0, -, -, +

Drop the two 0s → n = 18; plus signs: 3, minus signs: 15

From Table J: n = 18, \alpha = 0.05 (two-tailed) → Critical value = 4

Step 3: Test value = smaller of (3, 15) = 3

Step 4: 3 \leq 4 → Reject H_0

Step 5: Sufficient evidence to reject the claim that the median is 40.

Example 13-2: Age of Foreign-Born Residents (Large Sample)

Problem

The median age of foreign-born U.S. residents is claimed to be at least 36.4 years. In a sample of n = 50 residents, 21 are older than 36.4. At \alpha = 0.05, test the claim.

H_0: MD \geq 36.4 \text{ (claim)} \qquad H_1: MD < 36.4

Example 13-2: Mathematical Solution

Solution

Since n = 50 \geq 26, use the z approximation.

Plus signs (older than 36.4): 21; Minus signs (younger): 29

X = smaller count = 21 (we use 21 because the test is left-tailed — checking if fewer people are above 36.4)

z = \frac{(X + 0.5) - n/2}{\sqrt{n}/2} = \frac{(21 + 0.5) - 25}{\sqrt{50}/2} = \frac{-3.5}{3.536} = -0.99

Step 4: Critical value (left-tailed, \alpha = 0.05): -1.65

Since -0.99 > -1.65 → Fail to reject H_0

Step 5: Not enough evidence to reject the claim that the median age is at least 36.4 years.

Example 13-2: R Solution

n       <- 50
n_above <- 21
n_below <- n - n_above  # 29
X       <- min(n_above, n_below)  # 21

z_stat <- ((X + 0.5) - n/2) / (sqrt(n)/2)
z_crit <- qnorm(0.05)  # left-tailed

cat("X (smaller count) =", X, "\n")
X (smaller count) = 21 
cat("z test value =", round(z_stat, 3), "\n")
z test value = -0.99 
cat("z critical value =", round(z_crit, 3), "\n")
z critical value = -1.645 
cat("Decision:", ifelse(z_stat < z_crit, "Reject H0", "Fail to reject H0"), "\n")
Decision: Fail to reject H0

Section 13-3: The Wilcoxon Rank Sum Test

Wilcoxon Rank Sum Test: Overview

Purpose

Used for two independent samples when normality cannot be assumed. It is the nonparametric counterpart of the independent-samples t test.

Both sample sizes must be \geq 10.

Idea: Combine both samples, rank all values together, then compare rank sums. If groups differ, one group’s ranks will be consistently higher than the other’s.

Wilcoxon Rank Sum Test: Formulas

Formulas

Let n_1 = smaller sample size, n_2 = larger sample size, R = sum of ranks for the smaller group.

\mu_R = \frac{n_1(n_1 + n_2 + 1)}{2} \qquad \sigma_R = \sqrt{\frac{n_1 n_2 (n_1 + n_2 + 1)}{12}}

z = \frac{R - \mu_R}{\sigma_R}

Use Table E for critical values (standard normal).

Example 13-4: Obstacle Course Times

Problem

Two independent groups (Army: n=12, Marines: n=11) complete an obstacle course. At \alpha = 0.05, test whether there is a difference in completion times.

Army 15 18 16 17 13 22 24 17 19 21 26 28
Marines 14 9 16 19 10 12 11 8 15 18 25

Example 13-4: Mathematical Solution

Solution

Step 1: H_0: No difference in times; H_1: There is a difference (claim)

Step 2: Two-tailed, \alpha = 0.05 → z_{crit} = \pm 1.96

Step 3: Combine and rank all 23 values, then sum ranks for Marines (n_1 = 11):

R = 1+2+3+4+5+7+8.5+10.5+14.5+16.5+21 = 93

\mu_R = \frac{11(11+12+1)}{2} = 132 \qquad \sigma_R = \sqrt{\frac{11 \cdot 12 \cdot 24}{12}} = 16.2

z = \frac{93 - 132}{16.2} = -2.41

Step 4: |-2.41| > 1.96 → Reject H_0

Step 5: Sufficient evidence that times differ between the two groups.

Example 13-4: R Solution

army    <- c(15,18,16,17,13,22,24,17,19,21,26,28)
marines <- c(14,9,16,19,10,12,11,8,15,18,25)

# Wilcoxon rank sum test (Mann-Whitney)
result <- wilcox.test(army, marines, alternative = "two.sided", correct = FALSE)

Section 13-4: The Wilcoxon Signed-Rank Test

Wilcoxon Signed-Rank Test: Overview

Purpose

Used for two dependent (paired) samples when normality cannot be assumed. It is the nonparametric counterpart of the paired t test.

Unlike the sign test, this method incorporates the magnitude of each difference, not just its direction.

For n \leq 30: use Table K for critical values.

For n > 30: use the z approximation: z = \frac{w_s - \dfrac{n(n+1)}{4}}{\sqrt{\dfrac{n(n+1)(2n+1)}{24}}} where w_s = smaller absolute rank sum.

Signed-Rank Procedure

Step-by-Step Procedure

  1. Compute differences D = X_B - X_A; discard any D = 0
  2. Rank the absolute values |D| from smallest to largest (average ties)
  3. Restore the sign of each rank (+ or -) based on the sign of D
  4. Sum the positive ranks (W^+) and the negative ranks (W^-) separately
  5. Test value w_s = smaller of |W^+| and |W^-|
  6. Reject H_0 if w_s \leq critical value from Table K

Section 13-5: The Kruskal-Wallis Test

Kruskal-Wallis Test: Overview

Purpose

The nonparametric equivalent of one-way ANOVA. Compares three or more independent groups without requiring normality.

  • Each group must have at least 5 observations
  • The test statistic H follows a chi-square distribution with d.f. = k - 1
  • This is always a right-tailed test

Kruskal-Wallis Formula

H Statistic

H = \frac{12}{N(N+1)}\left(\frac{R_1^2}{n_1} + \frac{R_2^2}{n_2} + \cdots + \frac{R_k^2}{n_k}\right) - 3(N+1)

where: - R_i = sum of ranks for group i - n_i = sample size of group i - N = n_1 + n_2 + \cdots + n_k - k = number of groups

Critical value: \chi^2 with d.f. = k - 1 from Table G. Reject H_0 if H > \chi^2_{crit}.

Example 13-6: Hospital Infections

Problem

A researcher examines infection counts in three groups of hospitals. At \alpha = 0.05, test whether the infection distributions are the same.

Group A Group B Group C
557 476 105
315 232 110
920 80 167
178 116 155

Example 13-6: Mathematical Solution

Step 1: H_0: No difference in infection distributions (claim); H_1: Distributions differ

Step 2: d.f. = k - 1 = 2; Critical value = 5.991

Step 3: Rank all 12 values combined:

Value Group Rank
80 B 1
155 C 5
315 A 9

R_A = 7+9+11+12 = 39; R_B = 1+4+8+10 = 23; R_C = 2+3+5+6 = 16

H = \frac{12}{12 \cdot 13}\left(\frac{39^2}{4} + \frac{23^2}{4} + \frac{16^2}{4}\right) - 3(13) = 5.346

Step 4: 5.346 < 5.991 → Fail to reject H_0

Step 5: Insufficient evidence of a difference in infections across hospital groups.

Section 13-6: Spearman Rank Correlation Coefficient and the Runs Test

Spearman Rank Correlation: Overview

Purpose

The nonparametric equivalent of Pearson’s r. Used when data are ranked or when normality cannot be assumed.

r_s = 1 - \frac{6\sum d^2}{n(n^2 - 1)}

where d = difference between paired ranks, n = number of data pairs.

  • r_s = +1: perfect positive rank agreement
  • r_s = -1: perfect inverse rank agreement
  • r_s \approx 0: no rank relationship

Use Table L for critical values when n \leq 30.

The Runs Test: Overview

What Is a Run?

A run is a maximal sequence of identical symbols (letters or labels) — preceded or followed by a different symbol or by the beginning/end of the sequence.

Purpose: Test whether a sequence of observations is random.

  • Too few runs → data are clustered (not random)
  • Too many runs → data alternate too regularly (not random)

Use Table M (two-tailed, \alpha = 0.05) to find the acceptable range of runs.

Example 13-8: Counting Runs

Problem

Count the number of runs in each sequence.

a. M M F F F M F F

b. H T H H H

c. A B A A A B B A B B B

Example 13-8: Solution

Solutions

a. MM | FFF | M | FF → 4 runs

b. H | T | HHH → 3 runs

c. A | B | AAA | BB | A | BBB → 6 runs

count_runs <- function(seq) {
  n <- length(seq)
  if (n == 0) return(0)
  sum(seq[-1] != seq[-n]) + 1
}

a <- c("M","M","F","F","F","M","F","F")
b <- c("H","T","H","H","H")
d <- c("A","B","A","A","A","B","B","A","B","B","B")

cat("Runs in a:", count_runs(a), "\n")
Runs in a: 4 
cat("Runs in b:", count_runs(b), "\n")
Runs in b: 3 
cat("Runs in c:", count_runs(d), "\n")
Runs in c: 6

Example 13-10: Ages of Drug Program Participants

Problem

Twenty people enroll in a drug program in this order of ages: 18, 36, 19, 22, 25, 44, 23, 27, 27, 35, 19, 43, 37, 32, 28, 43, 46, 19, 20, 22

At \alpha = 0.05, test whether ages occur at random.

Example 13-10: Mathematical Solution

Solution

Step 1: H_0: Ages occur at random (claim); H_1: Not random

Step 2: - Sorted ages: 18 19 19 19 20 22 22 23 25 27 27 28 32 35 36 37 43 43 44 46 - Median = 27 (average of 10th and 11th values) - Replace each age: A (above 27), B (below 27); discard values = 27

Sequence after replacement (dropping 27s): B A B B B A B A B | A A A A A A | B B B

Step 3: Runs: B | A | BBB | A | B | A | B | AAAAAA | BBB → 9 runs

n_1 = n_2 = 9 (9 above, 9 below median, after dropping 27s)

Step 4: Table M, n_1 = n_2 = 9 → acceptable range: [5, 15]

Since 9 falls within [5, 15] → Fail to reject H_0

Step 5: Insufficient evidence that ages are non-random.

Example 13-10: R Solution

ages <- c(18,36,19,22,25,44,23,27,27,35,19,43,37,32,28,43,46,19,20,22)
med  <- median(ages)

labels <- ifelse(ages > med, "A", ifelse(ages < med, "B", NA))
labels <- labels[!is.na(labels)]  # drop values equal to median

n_A    <- sum(labels == "A")

When to Use Nonparametric Tests

Decision Guidelines

  • Use parametric tests when their assumptions (normality, equal variance) are met — they are more powerful
  • Use nonparametric tests when:
    • Population is clearly non-normal
    • Data are ordinal or nominal
    • Small samples with no normality guarantee
    • Hypothesis involves the median rather than the mean
    • Testing for randomness (runs test)
