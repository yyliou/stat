第7-1節：信賴區間

估計

推論統計的一個面向是估計：由樣本所得的資訊推估參數值的過程。

我們以樣本測度（統計量）估計母體測度（參數）——以樣本平均數估計母體平均數，以樣本比例估計母體比例。這樣使用的統計量稱為估計式。

估計

估計是由樣本所獲得的資訊推估某一參數值的過程。

本章各項程序的共同假設

  1. 樣本必須是隨機抽取的。
  2. 樣本大小 n \geq 30，或當 n < 30 時母體為常態或近似常態分配。

第二項假設可用第6章的方法檢查：看直方圖是否呈鐘形、檢查有無離群值，並觀察常態分位圖上的點是否接近一直線。

點估計

某大學校長隨機抽取 100 名學生，算得平均年齡為 22.3 歲。若據此推斷全體學生的平均年齡為 22.3 歲，這就是一個點估計。

點估計

點估計是對某一參數所做的單一數值估計。母體平均數 \mu 的最佳點估計是樣本平均數 \bar{X}。

良好估計式的三項性質

  1. 估計式應為不偏估計式——由特定大小的樣本所得各估計值的期望值（平均數）等於被估計的參數。
  2. 估計式應具一致性——隨著樣本數增加，估計式的值會趨近被估計的參數值。
  3. 估計式應為相對有效估計式——在所有可用來估計該參數的統計量中，它的變異數最小。

區間估計

由於抽樣誤差，樣本平均數幾乎總是與母體平均數有些差距，而且我們無從知道某一個點估計離 \mu 有多近。正因如此，統計學家偏好使用區間估計。

區間估計

某一參數的區間估計是用來估計該參數的一個區間或一段數值範圍。這個估計可能包含、也可能不包含被估計的參數值。

全體學生平均年齡的區間估計可能是 21.9 < \mu < 22.7，或 22.3 \pm 0.4 歲；比例的區間估計可能是 0.107 < p < 0.113，或 11\% \pm 0.3\%。

信賴區間也可以用括號寫成 (21.9,\ 22.7) 與 (10.7\%,\ 11.3\%)。

信賴水準與信賴區間

信賴水準

某一參數區間估計的信賴水準，是指在抽取大量樣本、並對同一參數重複進行估計程序的前提下，該區間估計包含此參數的機率。

信賴區間

信賴區間是利用樣本所得資料、並搭配指定的信賴水準所決定的特定區間估計。

常用的信賴區間有三種：90%、95% 與 99% 信賴區間。

信賴水準與信賴區間

母體的平均數或比例是一個固定值。由某一個樣本建構出的信賴區間，不是包含該參數、就是不包含。若對某特定大小的所有可能樣本都建構 95% 信賴區間，其中有 95% 會包含該母體參數。

若要更有信心——由 95% 提高到 99%——就必須把區間加寬。大學生平均年齡的 99% 信賴區間可能是 21.7 < \mu < 22.9，或 22.3 \pm 0.6。這其中存在取捨。

注意

信賴水準描述的是程序的長期表現，而不是某一個特定區間。區間一旦算出來，參數不是在裡面、就是不在裡面。

臨界值 z_{\alpha/2}

希臘字母 \alpha 代表標準常態分配曲線兩側尾端的總面積，\alpha/2 則代表每一側尾端的面積。z_{\alpha/2} 稱為臨界值。

所述的信賴水準即為 1 - \alpha 的百分比：

  • 95% 信賴區間：\alpha = 0.05，因為 1 - 0.05 = 0.95
  • 99% 信賴區間：\alpha = 0.01，因為 1 - 0.01 = 0.99

臨界值 z_{\alpha/2}

表 A-4 是查出這些臨界值的紙本途徑，qnorm() 則是 R 的途徑。95% 信賴區間取 z_{\alpha/2} = 1.960，99% 信賴區間取 z_{\alpha/2} = 2.576。

critical_z <- qnorm(1 - (1 - confidence_level) / 2)

knitr::kable(data.frame(Confidence = paste0(confidence_level * 100, "%"),

誤差界限

誤差界限

誤差界限（也稱為估計的最大誤差）是參數的點估計值與該參數真值之間最大的可能差距。

在學生年齡的例子中，信賴區間為 21.9 < \mu < 22.7 或 22.3 \pm 0.4，誤差界限即為 0.4。在比例區間 10.7\% < p < 11.3\% 或 11\% \pm 0.3\% 中，誤差界限為 0.003，即 0.3%。

對某一特定的 \alpha（例如 \alpha = 0.05），有 95% 的樣本平均數或樣本比例會落在母體平均數或母體比例兩側此一誤差值之內。

以 R 呈現 95% 信賴區間

Prepare data——自 \mu = 50、\sigma = 10 的母體重複抽取 n = 25 的樣本。

set.seed(2023)
pop_mean <- 50
pop_sd <- 10
sample_size <- 25
margin_error <- qnorm(0.975) * pop_sd / sqrt(sample_size)

intervals <- tibble(
  sample_id = 1:40,
  sample_mean = replicate(40, mean(rnorm(sample_size, pop_mean, pop_sd)))) |>
  mutate(lower = sample_mean - margin_error,
         upper = sample_mean + margin_error,
         result = if_else(lower <= pop_mean & pop_mean <= upper,
                          "contains mu", "misses mu"))
sum(intervals$result == "contains mu")
[1] 38

第7-2節：\sigma 已知時母體平均數的信賴區間

假設條件與公式

\sigma 已知時求平均數信賴區間的假設

  1. 樣本是隨機樣本。
  2. n \geq 30，或當 n < 30 時母體為常態分配。

穩健

當變數的分配可以稍微偏離常態、卻仍能得到有效結論時，該統計方法稱為穩健的。

估計母體平均數時應使用樣本平均數：從同一母體重複抽樣時，樣本平均數的變動小於中位數或眾數。

假設條件與公式

\sigma 已知時母體平均數信賴區間的公式

\bar{X} - z_{\alpha/2}\left(\frac{\sigma}{\sqrt{n}}\right) < \mu < \bar{X} + z_{\alpha/2}\left(\frac{\sigma}{\sqrt{n}}\right)

90% 信賴區間取 z_{\alpha/2} = 1.645；95% 信賴區間取 z_{\alpha/2} = 1.960；99% 信賴區間取 z_{\alpha/2} = 2.576。

其中 z_{\alpha/2}\left(\sigma/\sqrt{n}\right) 即為誤差界限。

平均數信賴區間的四捨五入規則

以原始資料計算母體平均數的信賴區間時，取到比原始資料多一位小數。

以樣本平均數與標準差計算時，取到與所給平均數相同位數的小數。

求其他的 z_{\alpha/2} 值

統計上有時會用到 90%、95%、99% 以外的信賴水準。以 98% 信賴區間為例，求 z_{\alpha/2} 的步驟是：

  1. 把 98% 化為 0.98，求 \alpha = 1 - 0.98 = 0.02。
  2. 除以 2：\alpha/2 = 0.02/2 = 0.01。
  3. 以 1.0000 - 0.01 = 0.9900 在表 A-4 中查出對應的 z 值；qnorm(0.99) 回傳同一個臨界值 z_{\alpha/2} = \mathbf{2.326}。

估計平均數所需的樣本大小

究竟要多大的樣本才能做出準確的估計？答案取決於三件事：誤差界限、母體標準差與信賴程度。

此公式由誤差界限公式 E = z_{\alpha/2}\left(\sigma/\sqrt{n}\right) 解 n 而得：

E\sqrt{n} = z_{\alpha/2}\,\sigma \quad \Longrightarrow \quad \sqrt{n} = \frac{z_{\alpha/2} \cdot \sigma}{E}

母體平均數區間估計所需最小樣本大小的公式

n = \left(\frac{z_{\alpha/2} \cdot \sigma}{E}\right)^2

其中 E 為誤差界限。必要時將答案無條件進位成整數：只要結果有小數部分，就取下一個整數作為樣本大小 n。

範例 7-4

外送時間所需的樣本大小

台中某外送平台的營運主管想估計每筆訂單的平均外送時間，誤差要在 2 分鐘之內，並希望有 99% 的信心。先前的研究顯示標準差為 4.5 分鐘。她應該抽取幾筆訂單？

（模擬資料）

範例 7-4

解題

由於 \alpha = 0.01（即 1 - 0.99），z_{\alpha/2} = 2.576，E = 2。代入公式。

n = \left(\frac{z_{\alpha/2} \cdot \sigma}{E}\right)^2 = \left[\frac{(2.576)(4.5)}{2}\right]^2 = 33.59

margin_error <- 2

required_n <- (qnorm(0.995) * pop_sd / margin_error)^2
round(required_n, 2)
[1] 33.59
ceiling(required_n)
[1] 34

進位後得 34。若要有 99% 的信心使估計值與真正平均數相差在 2 分鐘之內，該主管至少須抽取 34 筆訂單。

關於樣本大小的補充

注意

統計上多數情況採四捨五入；但決定樣本大小時，一律無條件進位到下一個整數。

實務要點

  • 當母體很大或為無限母體、或採放回抽樣時，母體大小與樣本大小的計算無關。
  • 公式需要 \sigma。若 \sigma 未知，可用先前樣本的標準差 s 估計，或以全距除以 4 估計。
  • 區間估計常以文字敘述呈現：「兩人家庭每週平均花費 84 美元購買食品雜貨，在 95% 信心下誤差在 3 美元以內」，即 81 < \mu < 87。

第7-3節：\sigma 未知時母體平均數的信賴區間

t 分配

多數情況下 \sigma 並不知道，必須以樣本標準差 s 估計。使用 s 時——尤其樣本數較小時——需要比 z_{\alpha/2} 更大的臨界值，才能維持所述的信賴水準。這些值來自 Student’s t 分配。

t 分配的特性

與標準常態分配相似之處：

  1. 呈鐘形。
  2. 對平均數左右對稱。
  3. 平均數、中位數與眾數皆為 0，且位於分配的中央。
  4. 曲線趨近但永不接觸 x 軸。

與標準常態分配相異之處：

  1. 變異數大於 1。
  2. t 分配其實是依自由度而定的一族曲線，自由度與樣本大小有關。
  3. 隨著樣本數增加，t 分配趨近標準常態分配。

自由度

自由度

自由度是在算出某一樣本統計量之後，仍可自由變動的數值個數；當一個分配是由一族曲線構成時，自由度告訴研究者該用哪一條曲線。

若 5 個數值的平均數是 10，則其中 4 個可以自由變動；一旦前 4 個確定，第 5 個就必須是特定的數，好讓總和等於 50。因此 \text{d.f.} = 5 - 1 = 4。

自由度以 d.f. 表示。求平均數的信賴區間時，\text{d.f.} = n - 1。（本書後面某些檢定的自由度不是 n - 1。）

注意

t_{\alpha/2} 取自表 A-5 最上方標示 Confidence Intervals 的那一列；標示 One tail 與 Two tails 的兩列屬於第8章，此處不可使用。當自由度大於 30 且落在兩個表列值之間時，查表的慣例是無條件捨去到較小的表列值（較保守的作法）：d.f. = 68 視為 65。此慣例只是查表的輔助；qt() 接受確切的自由度，兩者不一致時，投影片一律採用 R 算出的值。

範例 7-5

查出 t 臨界值

樣本大小為 18 時，求 95% 信賴區間的 t_{\alpha/2} 值。

範例 7-5

解題

\text{d.f.} = 18 - 1 = 17。在表 A-5 左欄找到 17，並在標示 Confidence Intervals 的列中找到 95%；qt(0.975, df = 17) 回傳同一個臨界值 t_{\alpha/2} = \mathbf{2.110}。

[1] 2.11

在 R 中，信賴區間的臨界值一律是 qt(1 - alpha/2, df = n - 1)；95% 信賴區間即 qt(0.975, df = n - 1)。

\sigma 未知時平均數的公式

\sigma 未知時母體平均數信賴區間的公式

\bar{X} - t_{\alpha/2}\left(\frac{s}{\sqrt{n}}\right) < \mu < \bar{X} + t_{\alpha/2}\left(\frac{s}{\sqrt{n}}\right)

自由度為 n - 1。

\sigma 未知時求平均數信賴區間的假設

  1. 樣本是隨機樣本。
  2. n \geq 30，或當 n < 30 時母體為常態分配。

第7-4節：比例的信賴區間與樣本大小

比例

比例代表整體中的一部分，可以用分數、小數或百分比表示。若某快遞在台北配送的包裹中有 12% 送往超商取貨點，則 12\% = 0.12 = \frac{12}{100} = \frac{3}{25}，而隨機抽出一件包裹送往超商取貨點的機率為 0.12。

比例的符號

p = \text{母體比例} \qquad \hat{p} = \text{樣本比例（讀作 "p hat"）}

樣本比例為

\hat{p} = \frac{X}{n} \qquad \text{且} \qquad \hat{q} = \frac{n - X}{n} \quad \text{或} \quad \hat{q} = 1 - \hat{p}

其中 X 為樣本中具有所關切特徵的單位數，n 為樣本大小。

當 \hat{p} 與 \hat{q} 以小數或分數表示時，\hat{p} + \hat{q} = 1；以百分比表示時，\hat{p} + \hat{q} = 100\%。母體亦然：p + q = 1。

範例 7-8

超商取貨

隨機抽取某台灣電商平台的 180 位網購消費者，其中 63 人選擇超商取貨而非宅配到府。求 \hat{p} 與 \hat{q}，其中 \hat{p} 為選擇超商取貨的消費者比例。

（模擬資料）

範例 7-8

解題

本例中 X = 63、n = 180。

\hat{p} = \frac{X}{n} = \frac{63}{180} = 0.35 = 35\% \hat{q} = \frac{n - X}{n} = \frac{180 - 63}{180} = \frac{117}{180} = 0.65 = 65\%

pickup_count <- 63
sample_size <- 180

p_hat <- pickup_count / sample_size
c(p_hat = p_hat, q_hat = 1 - p_hat)
p_hat q_hat 
 0.35  0.65

因此有 65% 的消費者選擇宅配到府。

比例的信賴區間

p 的點估計使用樣本比例 \hat{p}，它是不偏、一致且相對有效的估計式。當樣本數不超過母體的 5% 時，\hat{p} 的抽樣分配近似常態，其平均數為 p、標準差為 \sqrt{pq/n}。

比例信賴區間的公式

\hat{p} - z_{\alpha/2}\sqrt{\frac{\hat{p}\hat{q}}{n}} < p < \hat{p} + z_{\alpha/2}\sqrt{\frac{\hat{p}\hat{q}}{n}}

適用條件為 n\hat{p} 與 n\hat{q} 皆大於或等於 5。其誤差界限為 E = z_{\alpha/2}\sqrt{\hat{p}\hat{q}/n}。

比例的信賴區間

求母體比例信賴區間的假設

  1. 樣本是隨機樣本。
  2. 滿足二項實驗的各項條件（見第5章）。

比例信賴區間的四捨五入規則

取到小數第三位。

注意

題目若直接給出某個百分比，將其化為小數後即為 \hat{p}。若申請者中有 12% 為男性，則 \hat{p} = 0.12。

比例所需的樣本大小

母體比例區間估計所需最小樣本大小的公式

n = \hat{p}\hat{q}\left(\frac{z_{\alpha/2}}{E}\right)^2

必要時無條件進位成整數。

需要分成兩種情況考慮：

  1. 若已有 \hat{p} 的某個近似值（例如來自先前的研究），即以該值代入公式。
  2. 若沒有 \hat{p} 的任何近似值，則取 \hat{p} = 0.5。因為 \hat{p} = \hat{q} = 0.5 時乘積 \hat{p}\hat{q} 最大，如此可確保樣本夠大、預測足夠準確。

第二種作法的缺點是可能得到比實際所需更大的樣本。

第7-5節：變異數與標準差的信賴區間

卡方分配

在統計上，變數的變異數與標準差和平均數同等重要。製造必須互相接合的水管時，管徑的變異必須夠小；製造藥品時，藥錠中藥量的變異數決定病患能否獲得正確劑量。

要計算這類信賴區間，需要一個新的分配：卡方分配，記為 \chi^2（希臘字母 chi，讀作「kai」）。當由變異數為 \sigma^2 的常態母體隨機抽樣時，(n-1)s^2/\sigma^2 的各個值即構成卡方分配。

卡方分配的特性

  1. 所有卡方值都大於或等於 0。
  2. 卡方分配是依自由度而定的一族曲線。
  3. 每一條卡方分配曲線下的面積等於 1。
  4. 卡方分配為右偏。

自由度約達 100 時，卡方分配會變得相當對稱。

卡方分配曲線族

Prepare data

chi_curves <- expand_grid(df = c(1, 4, 9, 15),

  mutate(density = dchisq(x, df),
         curve = fct_inorder(paste("d.f. =", df)))

查出兩個臨界值

由於卡方分配不對稱，公式中要使用兩個不同的值：\chi^2_{\text{left}} 與 \chi^2_{\text{right}}。

表 A-6 的左欄為自由度，最上一列為臨界值右側的面積。以 95% 信賴區間為例：

  1. 把 95% 化為小數並以 1 減去：1 - 0.95 = 0.05。
  2. 除以 2：\alpha/2 = 0.05/2 = 0.025。此欄給出 \chi^2_{\text{right}}。
  3. 以 1 減去 \alpha/2：1 - 0.025 = 0.975。此欄給出 \chi^2_{\text{left}}。
  4. 查 \text{d.f.} = n - 1 所在的列。

注意

若表 A-6 中沒有所需的自由度，使用表中最接近的較小值。例如 \text{d.f.} = 53 時改用 \text{d.f.} = 50。這是查表時較保守的作法；qchisq() 接受確切的自由度，兩者不一致時，投影片一律採用 R 算出的值。

n = 20 時，求 95% 信賴區間的 \chi^2_{\text{right}} 與 \chi^2_{\text{left}}。

範例 7-13

解題

求 \chi^2_{\text{right}}：先算 1 - 0.95 = 0.05，再將 0.05 除以 2 得 0.025。 求 \chi^2_{\text{left}}：再算 1 - 0.025 = 0.975。

然後以 \text{d.f.} = n - 1 = 20 - 1 = 19 查表 A-6 的 0.975 與 0.025 兩欄。

\chi^2_{\text{right}} = 32.852 \qquad \chi^2_{\text{left}} = 8.907

round(c(chi_right = qchisq(0.975, df = degrees_freedom),
        chi_left  = qchisq(0.025, df = degrees_freedom)), 3)
chi_right  chi_left 
   32.852     8.907

變異數與標準差的公式

變異數信賴區間的公式

\frac{(n-1)s^2}{\chi^2_{\text{right}}} < \sigma^2 < \frac{(n-1)s^2}{\chi^2_{\text{left}}} \qquad \text{d.f.} = n - 1

標準差信賴區間的公式

\sqrt{\frac{(n-1)s^2}{\chi^2_{\text{right}}}} < \sigma < \sqrt{\frac{(n-1)s^2}{\chi^2_{\text{left}}}} \qquad \text{d.f.} = n - 1

\sigma^2 與 \sigma 的有用估計值分別是 s^2 與 s。題目若給的是樣本標準差 s，代入時務必先平方；若給的是樣本變異數 s^2，則不要再平方，因為變異數已是平方單位。

變異數與標準差的公式

求變異數或標準差信賴區間的假設

  1. 樣本是隨機樣本。
  2. 母體必須為常態分配。

變異數或標準差信賴區間的四捨五入規則

以原始資料計算時，取到比原始資料多一位小數。

以樣本變異數或標準差計算時，取到與所給樣本變異數或標準差相同位數的小數。

範例 7-14

某電子廠的品管工程師抽驗 30 個生產批次，發現不良率（每千件的不良品數）的標準差為 1.6。求不良率之變異數與標準差的 95% 信賴區間。假設該變數為常態分配。

（模擬資料）

解題

由於 \alpha = 0.05、自由度為 29，兩個臨界值為 \chi^2_{\text{left}} = 16.047 與 \chi^2_{\text{right}} = 45.722。

\frac{(30-1)(1.6)^2}{45.722} < \sigma^2 < \frac{(30-1)(1.6)^2}{16.047} \mathbf{1.62 < \sigma^2 < 4.63}

標準差方面，將兩個上下限各取平方根：

\mathbf{1.27 < \sigma < 2.15}

範例 7-14

解題

以 R 計算

sample_sd <- 1.6
degrees_freedom <- 30 - 1

chi_limits <- qchisq(c(0.975, 0.025), df = degrees_freedom)
round(chi_limits, 3)
[1] 45.722 16.047
variance_limits <- degrees_freedom * sample_sd^2 / chi_limits
round(variance_limits, 2)
[1] 1.62 4.63
round(sqrt(variance_limits), 2)
[1] 1.27 2.15

根據 30 個批次的樣本，我們有 95% 的信心認為不良率的真實變異數介於 1.62 與 4.63 之間，真實標準差介於 1.27 與 2.15 之間。

範例 7-15

客服中心的每日來電量

求某客服中心每日來電件數之變異數與標準差的 90% 信賴區間。所用樣本為隨機抽取的 10 天。假設其分配近似常態。

124   127   130   130   135
140   148   155   158   163

（模擬資料）

範例 7-15

解題

步驟 1 求資料的變異數：s^2 = 198。

步驟 2 以 10 - 1 = 9 的自由度，由表 A-6 查 \chi^2_{\text{right}} 與 \chi^2_{\text{left}}。取 \alpha/2 = 0.05 與 1 - \alpha/2 = 0.95：\chi^2_{\text{right}} = 16.919，\chi^2_{\text{left}} = 3.325。

步驟 3 代入公式。

\frac{(10-1)(198)}{16.919} < \sigma^2 < \frac{(10-1)(198)}{3.325} \mathbf{105.3 < \sigma^2 < 535.9} \sqrt{105.3} < \sigma < \sqrt{535.9} \qquad \Longrightarrow \qquad \mathbf{10.3 < \sigma < 23.1}

第7章詞彙

假設 · 卡方分配 · 信賴區間 · 信賴水準 · 一致估計式 · 自由度 · 估計 · 估計式 · 區間估計 · 誤差界限 · 點估計 · 比例 · 相對有效估計式 · 穩健 · t 分配 · 不偏估計式

重要公式

母體平均數的信賴區間

\sigma 已知時母體平均數的信賴區間（當 n \geq 30 且 \sigma 未知時可用 s 代替）：

\bar{X} - z_{\alpha/2}\left(\frac{\sigma}{\sqrt{n}}\right) < \mu < \bar{X} + z_{\alpha/2}\left(\frac{\sigma}{\sqrt{n}}\right)

\sigma 未知時母體平均數的信賴區間，\text{d.f.} = n - 1：

\bar{X} - t_{\alpha/2}\left(\frac{s}{\sqrt{n}}\right) < \mu < \bar{X} + t_{\alpha/2}\left(\frac{s}{\sqrt{n}}\right)

估計平均數所需的樣本大小，其中 E 為誤差界限：

n = \left(\frac{z_{\alpha/2} \cdot \sigma}{E}\right)^2

重要公式

比例、變異數與標準差

比例的信賴區間，其中 \hat{p} = X/n、\hat{q} = 1 - \hat{p}：

\hat{p} - z_{\alpha/2}\sqrt{\frac{\hat{p}\hat{q}}{n}} < p < \hat{p} + z_{\alpha/2}\sqrt{\frac{\hat{p}\hat{q}}{n}} \qquad n = \hat{p}\hat{q}\left(\frac{z_{\alpha/2}}{E}\right)^2

變異數與標準差的信賴區間，\text{d.f.} = n - 1：

\frac{(n-1)s^2}{\chi^2_{\text{right}}} < \sigma^2 < \frac{(n-1)s^2}{\chi^2_{\text{left}}} \qquad \sqrt{\frac{(n-1)s^2}{\chi^2_{\text{right}}}} < \sigma < \sqrt{\frac{(n-1)s^2}{\chi^2_{\text{left}}}}

重點整理

重點

  • 估計是以樣本統計量推估參數；良好的估計式應為不偏、一致且相對有效，而 \bar{X} 是 \mu 的最佳點估計
  • 點估計是單一數值，區間估計是一段範圍，其信賴水準是這類區間長期而言捕捉到參數的機率
  • 誤差界限（估計的最大誤差）是點估計與參數之間最大的可能差距；信賴水準越高，區間越寬
  • \sigma 已知時用 z_{\alpha/2} 與 \sigma；\sigma 未知時用 t_{\alpha/2} 與 s，且 \text{d.f.} = n - 1——若 n < 30，變數必須為常態分配
  • 樣本大小由 n = \left(z_{\alpha/2}\sigma/E\right)^2 與 n = \hat{p}\hat{q}\left(z_{\alpha/2}/E\right)^2 求得，且一律無條件進位；母體大小無關緊要
  • 比例方面，\hat{p} = X/n、\hat{q} = 1 - \hat{p}，區間需滿足 n\hat{p} \geq 5 與 n\hat{q} \geq 5，上下限取到小數第三位；\hat{p} 未知時取 \hat{p} = 0.5
  • \sigma^2 與 \sigma 的信賴區間使用右偏的卡方分配與兩個臨界值，且必須假設母體為常態分配
