第2-1節：資料的組織

原始資料

研究者最初收集到某個變數的資料時，這些數值仍是未經處理的原始樣貌。

原始資料

資料以最初收集到的形式存在時，稱為原始資料（raw data）。

次數分配

次數分配

次數分配（frequency distribution）是把原始資料以表格形式整理，使用組（class）與次數（frequency）來呈現。

  • 每一筆原始資料都被歸入一個量化或質化的類別，這個類別稱為組。
  • 一組的次數，就是落在該組內的資料個數。

現在可以做出一般性的觀察：這項研究中大多數的富豪年齡在45歲以上。27、35、36、44……這些數值稱為組限（class limits）。

次數分配的三種類型

類型 使用時機
類別次數分配 資料可以歸入特定類別——名目或順序尺度的資料，例如政黨傾向、宗教信仰或主修領域
分組次數分配 資料的全距很大，需要用寬度超過一個單位的組
未分組次數分配 資料的全距很小，每一組就是單一的資料值

類別次數分配

類別次數分配用於可以歸入特定類別的資料。

百分比與相對次數

各組所佔的百分比為

\% = \frac{f}{n} \cdot 100

其中 f 是該組的次數，n 是資料總數。百分比通常不是次數分配的必要欄位，但可以加上去，因為圓形圖等圖形會用到。百分比的小數形式就稱為相對次數（relative frequency）。

分組次數分配

當資料的全距很大時，就必須把資料分成寬度超過一個單位的組，結果稱為分組次數分配。

組限 組界 次數
58–64 57.5–64.5 1
65–71 64.5–71.5 6
72–78 71.5–78.5 10
79–85 78.5–85.5 14
86–92 85.5–92.5 12
93–99 92.5–99.5 5
100–106 99.5–106.5 2
合計 50

50位隨機選出的大學生的血糖值（mg/dL）。

組限與組界

組限與組界

  • 下組限是該組可以包含的最小資料值；上組限是該組可以包含的最大資料值。
  • 組界用來分隔各組，使次數分配中沒有間隙。

求組界的通則

組限的小數位數應與資料相同，而組界則多一位小數且以5結尾。

\text{下組限} - 0.5 = 58 - 0.5 = 57.5 \qquad \text{上組限} + 0.5 = 64 + 0.5 = 64.5

若資料到小數第一位，組限7.8–8.8的組界就是7.75–8.85（減去與加上0.05）。

組距與組中點

組距與組中點

組距是下一組的下（或上）組限減去本組的下（或上）組限：65 - 58 = 7。也可以用同一組的上組界減下組界：64.5 - 57.5 = 7。

組中點 X_m 為

X_m = \frac{\text{下組界} + \text{上組界}}{2} \quad\text{或}\quad X_m = \frac{\text{下組限} + \text{上組限}}{2}

血糖資料第一組的 X_m = \dfrac{57.5 + 64.5}{2} = 61，或 \dfrac{58 + 64}{2} = 61。

組距與組中點

注意

不要用同一組的上組限減下組限，那會得到錯誤答案——64 - 58 = 6，而真正的組距是7。

若組距是偶數，組中點會出現小數：組界為5.5與11.5時，X_m = \dfrac{5.5 + 11.5}{2} = 8.5。

建立分組次數分配的規則

六項規則

  1. 組數應介於 5 到 20 組之間——足以清楚描述所收集的資料。
  2. 組距最好（但非絕對必要）是奇數，這樣組中點的位數才會與資料相同。使用電腦分組時，這項規則常常不被嚴格遵守。
  3. 各組必須互斥——組限不可重疊，資料才不會同時落入兩組。像10–20、20–30、30–40這樣的分組並不好：40歲的人該放哪一組？應改用10–20、21–31、32–42。
  4. 各組必須連續——即使某組沒有任何資料，仍須列出。唯一的例外是最前面或最後面次數為0的組。
  5. 各組必須周延——組數要足以容納所有資料。
  6. 各組的組距應相等，以免扭曲對資料的認識。例外情形是開放式的組。

開放式分配

開放式分配

第一組沒有明確下組限，或最後一組沒有明確上組限的次數分配，稱為開放式分配（open-ended distribution）。

年齡 次數 分鐘 次數
10–20 3 110以下 16
21–31 6 110–114 24
32–42 4 115–119 38

程序表

建立分組次數分配的步驟

步驟1——決定組別。

  • 找出最大值與最小值。
  • 求全距 R = H - L。
  • 選定想要的組數。
  • 用全距除以組數並無條件進位，求得組距。
  • 選一個起點（通常是最小值，或比最小值小的方便數字）；依序加上組距得到各組下組限。
  • 求各組上組限。
  • 求各組組界。

步驟2——劃記資料。

步驟3——由劃記求出各組次數，並計算累積次數。

步驟1——決定組別

H = 52、L = 18，所以 R = 52 - 18 = 34。分成7組時組距為 \frac{34}{7} \approx 4.9，無條件進位為5。從18起算，下組限依序為18、23、28……；23 - 1 = 22 得到第一組的上組限，因此各組為18–22、23–27……。組界則為17.5–22.5、22.5–27.5，依此類推。

步驟2與3——劃記資料並求出次數

class_breaks <- seq(17.5, 52.5, by = class_width)
class_limits <- c("18-22","23-27","28-32","33-37",

delivery_freq <- data.frame(delivery_times) |>
  mutate(Class = cut(delivery_times, breaks = class_breaks,
                     labels = class_limits)) |>
  count(Class, .drop = FALSE) |>

    Boundaries = paste0(head(class_breaks, -1), "-", tail(class_breaks, -1)),
    Midpoint   = head(class_breaks, -1) + class_width / 2,
    Cumulative = cumsum(Frequency)
  )

累積次數分配

累積次數分配

累積次數分配是顯示小於或等於某個特定數值（通常是上組界）的資料個數的分配。

做法是把小於或等於該組上組界的各組次數相加。以例題2-2來說，第一組的累積次數是 0 + 3 = 3；第二組是 0 + 3 + 9 = 12；第三組是 0 + 3 + 9 + 16 = 28。更快的做法是把本組次數加上前一組的累積次數：12 + 16 = 28。

未分組次數分配

當資料的全距相對較小時，可以用單一資料值作為每一組來建立次數分配。

未分組次數分配

未分組次數分配以單一資料值作為每一組，而不是用一段數值區間。

若資料是連續的，仍然可以使用組界：每個組值減0.5得到下組界，加0.5得到上組界。

為什麼要建立次數分配？

五個理由

  1. 以有意義、易理解的方式整理資料。
  2. 讓讀者判斷分配的性質或形狀。
  3. 方便後續計算平均數與離散程度的計算程序（第3-1、3-2節）。
  4. 讓研究者能繪製圖表來呈現資料（第2-2節）。
  5. 讓讀者能在不同資料集之間做比較。

第2-2節：直方圖、次數多邊形與肩形圖

以圖形呈現資料

統計圖形的目的，是把資料以圖像形式傳達給閱讀者。對多數人而言，看圖比看表格或次數分配中的數字更容易理解，對缺乏統計背景的讀者尤其如此。

研究中最常使用的三種圖形是

  1. 直方圖（histogram）。
  2. 次數多邊形（frequency polygon）。
  3. 累積次數圖，即肩形圖（ogive，讀作 o-jive）。

程序表

繪製直方圖、次數多邊形與肩形圖的步驟

步驟1. 畫出並標示 x 軸與 y 軸。

步驟2. 在 x 軸上，直方圖與肩形圖標示次數分配的組界，次數多邊形則標示組中點。

步驟3. 畫出各組的次數：直方圖畫成垂直長條，次數多邊形與肩形圖則連成折線。

註：次數多邊形的折線起點與終點都落在 x 軸上，而肩形圖的折線只有起點落在 x 軸上。

直方圖

直方圖

直方圖是用相鄰的垂直長條（除非某組次數為0）呈現資料的圖形，長條的高度代表各組的次數。

直方圖由 Karl Pearson 於 1891 年提出，他用它來呈現歷任首相任期的時間概念。

次數多邊形

次數多邊形

次數多邊形是把各組組中點上代表次數的點連成折線來呈現資料的圖形，次數由點的高度表示。

次數多邊形與直方圖是呈現同一筆資料的兩種不同方式，要用哪一種由研究者自行決定。

相對次數圖

前面的直方圖、次數多邊形與肩形圖都是以原始資料的次數繪製。這些分配也可以換成比例來表示，這樣的圖形就稱為相對次數圖。

何時該用相對次數

當我們在意的是落在某一組的資料比例，而不是實際的個數時，就使用相對次數。例如要比較費城（人口1,526,006）與伊利市（人口101,786）的成人年齡分配，若用實際個數，費城的每根長條都會遠高於伊利市。

把次數換成相對次數的做法是：用各組次數除以總次數。相對次數的總和恆為1。

分配的形狀

描述資料時，辨認分配的形狀非常重要，因為形狀也決定了後續章節中應該採用哪些統計方法。

形狀 說明
鐘形（丘形） 單一峰值，兩端逐漸下降；近似對稱
均勻形 基本上是平坦或矩形的
J形 左側資料很少，往右逐漸增加
反J形 與J形相反
右偏（正偏） 峰值偏左，資料往右逐漸拖尾
左偏（負偏） 資料集中在右側，往左逐漸拖尾
雙峰形 有兩個等高的峰
U形 兩端高、中間低

分配的形狀

實際的分配通常不會是完美的形狀，所以不必追求精確吻合，而是要辨認出整體的樣態。

分析直方圖或次數多邊形時

  • 它有一個峰還是兩個峰？只有一個峰的分配——鐘形、右偏、左偏——稱為單峰（unimodal）；有兩個等高峰的分配則是雙峰（bimodal）。
  • 它是相對平坦的，還是 U形的？
  • 資料是分散的，還是集中在中央？
  • 兩端極端處有沒有資料？那些可能是離群值（第3-3節）。
  • 直方圖中有沒有間隙？次數多邊形有沒有在頭尾以外的地方碰到 x 軸？
  • 資料是否偏向某一端，顯示分配是偏斜的？

第2-3節：其他類型的圖形

直方圖以外的選擇

除了直方圖、次數多邊形與肩形圖之外，統計上還常用幾種圖形：

  • 長條圖——用於質化或類別資料
  • 柏拉圖——長條依次數由高到低排列的長條圖
  • 時間序列圖——用於一段期間內收集的資料
  • 圓形圖——呈現部分與整體的關係
  • 點圖——每一筆資料在水平軸上方畫成一個點
  • 莖葉圖——結合排序與繪圖，並保留原始資料值

長條圖

長條圖

長條圖用垂直或水平長條呈現資料，長條的高度或長度代表資料的次數。

當資料是質化或類別資料時，可以用長條圖呈現。長條圖可以用水平長條，也可以用垂直長條。

柏拉圖

圓形圖

圓形圖

圓形圖是把一個圓依照分配中各類別次數所佔的百分比，分割成若干扇形或楔形。

各扇形的角度

\text{角度} = \frac{f}{n} \cdot 360^\circ

其中 f 是各組的次數，n 是次數總和。角度總和應為 360^\circ，百分比總和應為100%——不過四捨五入可能讓總和略有出入。

點圖

莖葉圖

leaves_by_stem <- function(values, lower_limits, width, decreasing = FALSE) {
  vapply(lower_limits, function(lo) {
    in_row <- values[values >= lo & values < lo + width]
    paste(sort(in_row %% 10, decreasing = decreasing), collapse = " ")
  }, character(1))
}

誤導性圖形

圖形提供視覺化的呈現，讓讀者比單看數字更容易分析與解讀資料。然而，繪製不當的圖形會扭曲資料，使讀者得到錯誤的結論。

某汽車製造商的廣告宣稱，過去10年賣出的車輛有98%仍在路上跑，並附上一張縱軸只從 95% 到 100% 的長條圖。若改用 0 到 100% 的尺度重畫，該廠商與競爭對手之間幾乎看不出差別。

用 R 看誤導性圖形

  maker   = c("本廠牌", "競爭者一", "競爭者二"),
  percent = c(98, 97, 96.5)
)

用 R 看誤導性圖形

ggplot(vehicles_on_road, aes(maker, percent, fill = maker)) +

當 y 軸從0到20時，增幅看起來很小；把尺度拉伸成只從12到14、每0.2一格之後，同樣的數值看起來卻像是大幅增加。

二維圖示

另一種誤導手法，是把一維的增加用二維圖形呈現而誇大差距。

假設某物流公司的每日包裹量從 20,000 件成長到 60,000 件，是原來的三倍（模擬資料）。若畫成兩根長條，比較的是長條的高度，只有一個維度，較高的長條就是較矮的三倍。若畫成直徑比同樣是 1 比 3 的兩個圓，差距看起來大得多，因為眼睛比較的是圓的面積，而較大的圓面積是較小的九倍。

誤導性圖形

注意

截斷尺度或用二維圖示呈現資料本身並沒有錯——但使用這些手法時，讀者必須對由圖形得出的結論保持警覺。在接受一張圖之前，先檢查：

  • 數值軸是從0開始，還是被截斷了？
  • 尺度是否被拉伸或壓縮，以誇大變化？
  • 圖示符號是依面積縮放，還是依高度縮放？
  • 座標軸是否省略了標籤或單位？y 軸沒有數字時，只能得到粗略的排序，無法判斷差距的真正大小。
  • 有沒有註明資料來源？來源能讓你查證提供資料的機構是否可靠。

總整理

圖形類型 最適合用於
直方圖 分組次數分配的次數；在組界上畫相鄰的垂直長條
次數多邊形 在組中點畫出次數並連成折線
肩形圖 在上組界畫出累積次數
長條圖 質化或類別資料；水平或垂直長條
柏拉圖 類別資料，長條由高到低排列
時間序列圖 一段特定期間內發生的資料
圓形圖 部分與整體的關係
點圖 每筆資料畫成一個點；找出極端值
莖葉圖 在呈現形狀的同時保留原始資料值

重要公式

重要公式

各組所佔的百分比：\displaystyle \% = \frac{f}{n} \cdot 100

全距：R = \text{最大值} - \text{最小值}

組距：\text{組距} = \text{上組界} - \text{下組界}

組中點： X_m = \frac{\text{下組界} + \text{上組界}}{2} \quad\text{或}\quad X_m = \frac{\text{下組限} + \text{上組限}}{2}

圓形圖各扇形的角度：\displaystyle \text{角度} = \frac{f}{n} \cdot 360^\circ

重點整理

重點

  • 原始資料——最初收集到的數值；未經整理之前幾乎看不出任何資訊
  • 次數分配——以組與次數把原始資料整理成表格
  • 三種類型——類別（特定類別）、分組（全距大）、未分組（全距小）
  • 組限／組界／組距／組中點——組限與資料同小數位，組界多一位且以5結尾，組距是相鄰兩組下組限之差
  • 六項規則——5到20組、組距最好為奇數、互斥、連續、周延、組距相等（開放式組例外）
  • 累積次數分配——小於或等於某特定數值的資料個數
  • 直方圖／次數多邊形／肩形圖——分別對應組界、組中點與累積次數
  • 相對次數圖——以比例取代個數；比較大小不同的資料集時必須使用
  • 分配的形狀——鐘形、均勻形、J形、反J形、右偏、左偏、雙峰形、U形
  • 其他圖形——長條圖、柏拉圖、時間序列圖、圓形圖、點圖、莖葉圖
  • 誤導性圖形——截斷或拉伸尺度、二維圖示與省略標籤都會扭曲訊息
