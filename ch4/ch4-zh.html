第 4-1 節：樣本空間與機率

重要詞彙

機率實驗

機率實驗（probability experiment）是一種能產生明確定義結果（稱為結果）的過程。

樣本空間與事件

  • 樣本空間（S）：一次機率實驗所有可能結果的集合
  • 結果（outcome）：一次試驗所產生的單一結果
  • 事件（E）：一個或多個結果——樣本空間的子集
  • 簡單事件：恰好只有一個結果的事件
  • 複合事件：包含兩個或兩個以上結果的事件

問題

古典機率

古典機率

當樣本空間中所有結果等可能發生時：

P(E) = \frac{n(E)}{n(S)} = \frac{\text{事件 } E \text{ 中的結果數}}{\text{樣本空間中的結果總數}}

機率規則

  1. 0 \leq P(E) \leq 1，對任何事件 E 均成立
  2. P(S) = 1（所有結果之和 = 1）
  3. P(\emptyset) = 0（不可能事件）
  4. \sum P(E_i) = 1，對所有簡單事件均成立

範例 4-5：抽一張牌

問題

從一副標準 52 張的撲克牌中抽一張牌，求抽到黑色 10 的機率。

P(黑色 10) = 2 / 52 = 0.0385 = 1/26

解題步驟

共有 2 張黑色 10（梅花 10、黑桃 10），牌的總數為 52。 P(\text{黑色 10}) = \frac{2}{52} = \frac{1}{26}

補集規則

事件 E 的補集（餘事件），記為 \bar{E}，包含所有不在 E 中的結果。

經驗機率

經驗機率（相對次數機率）是根據觀察到的資料計算的：

P(E) = \frac{\text{事件 } E \text{ 的次數}}{\text{總次數}} = \frac{f}{n}

第 4-2 節：機率的加法規則

互斥事件

互斥事件

若兩個事件 A 與 B 不能同時發生——即沒有共同結果——則稱它們為互斥事件。

加法規則 1——互斥事件

當兩個事件 A 與 B 互斥時： P(A \text{ 或 } B) = P(A) + P(B)

加法規則 2——非互斥事件

當 A 與 B 非互斥時： P(A \text{ 或 } B) = P(A) + P(B) - P(A \text{ 且 } B)

範例 4-15：擲骰子——互斥性

問題

擲一個骰子，判斷下列哪些事件對是互斥的：

    1. 出現 3 與出現奇數
    1. 奇數與小於 4 的數
    1. 大於 4 的數與小於 4 的數
(a) 奇數: 1 3 5 | 偶數: 2 4 6 | 重疊:  → 互斥
(b) {3} vs 奇數: 1 3 5 | 重疊: 3 → 非互斥
(c) 奇數: 1 3 5 vs <4: 1 2 3 | 重疊: 1 3 → 非互斥
(d) >4: 5 6 vs <4: 1 2 3 | 重疊:  → 互斥

範例 4-16：抽一張牌——互斥性

問題

抽一張牌，判斷下列哪些事件是互斥的：

    1. 7 與傑克（J）
    1. 梅花與國王（K）
    1. 人頭牌與 A
    1. 人頭牌與黑桃

第 4-3 節：乘法規則與條件機率

獨立事件與相依事件

獨立事件

若事件 A 的發生不影響事件 B 發生的機率，則稱 A 與 B 為獨立事件。

乘法規則 1——獨立事件

P(A \text{ 且 } B) = P(A) \cdot P(B)

對多個獨立事件：P(A_1 \text{ 且 } A_2 \cdots \text{ 且 } A_k) = P(A_1) \cdot P(A_2) \cdots P(A_k)

範例 4-23：擲硬幣並投骰子

問題

擲一枚硬幣並投一個骰子，求 P(正面且 4)。

P(正面且 4) = P(正面) × P(4) = 0.5 × 0.1666667 = 0.08333333 = 1/12
由樣本空間計算 P: 0.08333333

範例 4-24：抽牌（有放回）

問題

從一副牌中抽一張後放回，再抽第二張。求 P(先抽到 Q，再抽到 A)。

P(Q 後 A) = P(Q) × P(A) = 0.07692308 × 0.07692308 
          = 0.00591716 = 16/2704 = 1/169

範例 4-25：選取有色球（有放回）

問題

甕中有 3 個紅球、2 個藍球和 5 個白球。取出一個球，記錄後放回，再取第二個。求：

  1. P(2 個藍球)

  2. P(藍球後白球)

  3. P(紅球後藍球)

1. P(藍且藍)  = 0.2 × 0.2 = 0.04 = 4/100 = 1/25
2. P(藍且白)  = 0.2 × 0.5 = 0.1 = 1/10

範例 4-27：色盲

問題

約 9% 的男性有紅綠色盲。若隨機選取 3 名男性，求三人都有色盲的機率。

相依事件

相依事件

若第一個事件的結果或機率影響到第二個事件發生的機率，則稱這些事件為相依事件。

乘法規則 2——相依事件

P(A \text{ 且 } B) = P(A) \cdot P(B|A)

其中 P(B|A) 是在 A 已發生的條件下，B 發生的條件機率。

範例 4-28：大學犯罪

問題

某大學 2003 年發生 5 起竊盜案，2004 年 16 起，2005 年 32 起。研究人員隨機選取 2 件案例調查，求兩件都發生在 2004 年的機率。

竊盜案總數： 53 
P(兩件都在 2004 年) = 16/53 × 15/52 = 0.0871 = 60/689

範例 4-29：房屋保險與汽車保險

問題

某市 53% 的居民投保房屋險（H），其中 27% 的人也向同一家公司投保汽車險（A）。求 P(H 且 A)。

P(H 且 A) = P(H) × P(A|H) = 0.53 × 0.27 = 0.1431

問題

從一副牌中不放回地抽三張牌，求：

  3. P(依序抽到梅花、黑桃、紅心)

  4. P(3 張梅花)

範例 4-31：選取有色球（樹狀圖）

問題

箱 1 有 2 個紅球和 1 個藍球；箱 2 有 3 個藍球和 1 個紅球。擲硬幣：正面→箱 1；反面→箱 2，再取出一個球。求 P(紅球)。

P(紅球) = P(箱1)×P(紅|箱1) + P(箱2)×P(紅|箱2)
        = 0.5 × 0.6666667 + 0.5 × 0.25 
        = 0.3333333 + 0.125 = 0.4583333 = 11/24

條件機率

條件機率公式

在事件 A 已發生的條件下，事件 B 發生的條件機率：

P(B|A) = \frac{P(A \text{ 且 } B)}{P(A)}

範例 4-32：選取有色籌碼

問題

P(黑色籌碼且白色籌碼) = 15/56。P(第一次抽到黑色籌碼) = 3/8。求 P(白色 | 第一次黑色)。

P(白|黑) = P(黑且白) / P(黑) = 0.2678571 / 0.375 = 0.7142857 = 5/7

P(罰單|禁停) = P(禁停且罰單)/P(禁停) = 0.06 / 0.2 = 0.3

「至少」的機率

「至少一個」的策略

處理「至少一個」的問題時，使用補集： P(\text{至少一個}) = 1 - P(\text{一個都沒有})

範例 4-36：擲硬幣

問題

擲一枚硬幣 5 次，求 P(至少 1 次反面)。

P(全部正面) = (1/2)⁵ = 0.03125 = 1/32
P(至少 1 次反面) = 1 - 1/32 = 0.96875 = 31/32

範例 4-37：蝴蝶結領帶

問題

領帶銷售中有 3% 為蝴蝶結領帶。若隨機選取 4 位購買領帶的顧客，求 P(至少 1 人購買蝴蝶結領帶)。

P(沒有蝴蝶結領帶) = (0.97)⁴ = 0.8853 
P(至少 1 條蝴蝶結領帶) = 1 - 0.8853 = 0.1147

第 4-4 節：計數規則

三種計數規則

三種計數規則

為確定可能結果的總數：

  1. 基本計數原理：將每個步驟的選擇數相乘

  2. 排列規則：順序有關的排列方式

  3. 組合規則：順序無關的選取方式

基本計數原理

在 n 個依序發生的事件中，第一個事件有 k_1 種可能，第二個有 k_2 種，依此類推： \text{結果總數} = k_1 \cdot k_2 \cdot k_3 \cdots k_n

範例 4-38：擲硬幣並投骰子

問題

擲一枚硬幣並投一個骰子，求結果的總數。

結果總數 = 2 × 6 = 12 
樣本空間： H1, T1, H2, T2, H3, T3, H4, T4, H5, T5, H6, T6

階乘符號與排列

階乘符號

n! = n \cdot (n-1) \cdot (n-2) \cdots 1 \qquad \text{且} \qquad 0! = 1

排列規則

從 n 個物件中取 r 個進行排列（順序有關）： _nP_r = \frac{n!}{(n-r)!}

問題

組合

組合規則

從 n 個物件中選取 r 個，順序無關： _nC_r = \frac{n!}{(n-r)!\, r!}

關鍵區別： 在排列中，AB ≠ BA；在組合中，AB = BA。

組合（ 6 種）： AB, AC, AD, BC, BD, CD

第四章摘要

重要公式

概念 公式
古典機率 P(E) = n(E)/n(S)
經驗機率 P(E) = f/n
補集 P(\bar{E}) = 1 - P(E)
加法規則 1（互斥） P(A \text{ 或 } B) = P(A) + P(B)
加法規則 2 P(A \text{ 或 } B) = P(A) + P(B) - P(A \text{ 且 } B)
乘法規則 1（獨立） P(A \text{ 且 } B) = P(A) \cdot P(B)
乘法規則 2（相依） P(A \text{ 且 } B) = P(A) \cdot P(B\|A)
條件機率 P(B\|A) = P(A \text{ 且 } B)/P(A)
排列 _nP_r = n!/(n-r)!
組合 _nC_r = n!/[(n-r)!\,r!]
