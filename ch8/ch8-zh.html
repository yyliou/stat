本章概覽

統計假設檢定是一種決策程序，用於評估關於母體參數的主張。

重要詞彙

  • 統計假設：對母體參數的猜測
  • 虛無假設（H₀）：陳述無差異或無效果——即現狀
  • 對立假設（H₁）：研究主張；我們試圖支持的論點
  • 檢定值：用於在 H₀ 與 H₁ 之間做決定的計算統計量

第 8-1 節：假設檢定步驟

虛無假設與對立假設

假設結構

  • H₀（虛無假設）：包含等號（=、\leq、\geq）
  • H₁（對立／研究假設）：包含不等號（\neq、<、>）
  • 主張可能在 H₀ 或 H₁ 中

對立假設的方向決定了檢定的類型：

H₁ 包含 檢定類型
> 右尾檢定
< 左尾檢定
\neq 雙尾檢定

錯誤類型

第一類型錯誤與第二類型錯誤

決策 H₀ 為真 H₀ 為假
拒絕 H₀ 第一類型錯誤（α） 正確決策（1 − β）
不拒絕 H₀ 正確決策（1 − α） 第二類型錯誤（β）
  • α = P（第一類型錯誤）= 顯著水準
  • β = P（第二類型錯誤）
  • 常用的 α 值：0.10、0.05、0.01

臨界區域與臨界值

重要名詞

  • 臨界（拒絕）區域：導致拒絕 H₀ 的值域範圍
  • 非臨界區域：導致不拒絕 H₀ 的值域範圍
  • 臨界值：分隔兩個區域的邊界值

假設檢定五步驟程序

傳統方法

  1. 陳述假設並確認主張
  2. 查找適當表格中的臨界值
  3. 計算檢定值
  4. 做出決策（拒絕或不拒絕 H₀）
  5. 用淺顯語言摘要結果

第 8-2 節：均值的 z 檢定

均值的 z 檢定

公式

z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}

要求條件： - 母體標準差 σ 已知 - 若 n < 30，母體須近似常態分配

使用標準常態（z）分配求臨界值與 P 值。

範例 8-3

汽車在展示場停留天數（傳統法）

某研究者聲稱汽車在展示場平均停留超過 29 天。隨機抽取 30 輛汽車，得 X̄ = 30.1 天；σ = 3.8。使用 α = 0.05。

範例 8-3

解題

解題

某研究者聲稱男性運動鞋的平均價格低於 80 美元。抽取 36 雙鞋，得 X̄ = 75 美元，σ = 19.2 美元。使用 α = 0.10。

步驟 1： H₀：μ = 80 且 H₁：μ < 80 （主張；左尾檢定）

步驟 2： CV = −1.28

xbar <- 75; mu <- 80; sigma <- 19.2; n <- 36
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] -1.56

步驟 4： 由於 −1.56 < −1.28（落在臨界區域），拒絕 H₀。

步驟 5： 有足夠證據支持平均價格低於 80 美元的主張。

範例 8-5

問題

某研究者聲稱中風患者的平均復健費用不同於 24,672 美元。抽取 35 位患者，得 X̄ = 26,343 美元，σ = 3251 美元。使用 α = 0.01。

步驟 1： H₀：μ = 24672 且 H₁：\mu \neq 24672 （主張；雙尾檢定）

步驟 2： CV = ±2.58

xbar <- 26343; mu <- 24672; sigma <- 3251; n <- 35
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] 3.04

步驟 4： 由於 3.04 > 2.58（落在臨界區域），拒絕 H₀。

步驟 5： 有足夠證據得出復健費用不同於 24,672 美元的結論。

P 值方法

P 值決策規則

  • 計算 P 值：在 H₀ 為真的假設下，獲得至少與已計算之檢定統計量一樣極端的機率
  • 若 P 值 \leq \alpha → 拒絕 H₀
  • 若 P 值 > α → 不拒絕 H₀

步驟： 1. 陳述假設並確認主張 2. 計算檢定值 3. 求 P 值 4. 做出決策 5. 摘要結果

範例 8-6

問題

某研究者聲稱平均學費超過 5700 美元。抽取 36 所學校，得 X̄ = 5950 美元，σ = 659 美元。使用 α = 0.05。

步驟 1： H₀：μ = 5700 且 H₁：μ > 5700 （主張；右尾檢定）

xbar <- 5950; mu <- 5700; sigma <- 659; n <- 36
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] 2.28
# 右尾檢定的 P 值
p_val <- 1 - pnorm(z)
round(p_val, 4)
[1] 0.0114

步驟 4： 由於 P = 0.0113 < α = 0.05，拒絕 H₀。

步驟 5： 有足夠證據支持平均學費超過 5700 美元的主張。

範例 8-7

問題

某研究者聲稱某城市的平均風速為每小時 8 英里。抽取 32 天的資料，得 X̄ = 8.2 英里/小時，σ = 0.6。使用 α = 0.05。

步驟 1： H₀：μ = 8 （主張） 且 H₁：\mu \neq 8 （雙尾檢定）

xbar <- 8.2; mu <- 8; sigma <- 0.6; n <- 32
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] 1.89
# 雙尾 P 值
p_val <- 2 * (1 - pnorm(abs(z)))
round(p_val, 4)
[1] 0.0593

步驟 4： 由於 P = 0.0588 > α = 0.05，不拒絕 H₀。

步驟 5： 沒有足夠證據拒絕平均風速為每小時 8 英里的主張。

第 8-3 節：均值的 t 檢定

均值的 t 檢定

公式

t = \frac{\bar{X} - \mu}{s / \sqrt{n}}, \quad \text{自由度} = n - 1

使用時機： - σ 未知（以樣本 s 代替） - 若 n < 30，母體須近似常態分配

臨界值來自自由度為 n − 1 的 t 分配。

問題

某營養師聲稱 60% 的人會刻意避免攝入反式脂肪。調查 200 人後發現 128 人會避免攝入。在 α = 0.05 下，有足夠證據拒絕此主張嗎？

X <- 128; n <- 200; p <- 0.60; q <- 1 - p

第 8-5 節：變異數或標準差的 χ² 檢定

變異數的卡方檢定

公式

\chi^2 = \frac{(n-1)s^2}{\sigma^2}, \quad \text{自由度} = n - 1

假設條件： - 隨機樣本 - 母體為常態分配 - 觀測值相互獨立

三種檢定類型： 右尾（σ² > 某值）、左尾（σ² < 某值）、雙尾（\sigma^2 \neq 某值）

範例 8-21 至 8-23：求 χ² 臨界值 {.smaller}

問題

求各情境的卡方臨界值：

  • 8-22：自由度 = 10，α = 0.05，左尾檢定
  • 8-23：自由度 = 22，α = 0.05，雙尾檢定
# 8-21：右尾檢定
qchisq(1 - 0.05, df = 15)
[1] 24.99579
# 8-22：左尾檢定（使用 1 - α 求左尾）
qchisq(0.05, df = 10)

第 8-6 節：假設檢定的進階主題

信賴區間與假設檢定

重要關係

對於雙尾假設檢定：

  • 若在 α 下 H₀ 被拒絕 → (1 − α)·100% 信賴區間將不包含假設值
  • 若在 α 下 H₀ 不被拒絕 → (1 − α)·100% 信賴區間將包含假設值

這表示相同水準的假設檢定與信賴區間會得出相同的結論。

範例 8-30

糖的產量

糖袋標示應裝 5 磅。抽取 50 個袋子，得 X̄ = 4.6 磅，s = 0.7。在 α = 0.05 下，是否有證據顯示袋裝量不同於 5 磅？另求 95% 信賴區間。

範例 8-30

解題

解題

某研究者聲稱餵食特殊飼料的豬平均體重為 200 磅。抽取 10 頭豬，得 X̄ = 198.2，s = 3.3。在 α = 0.05 下，能拒絕此主張嗎？求 95% 信賴區間。

步驟 1： H₀：μ = 200 （主張） 且 H₁：\mu \neq 200 （雙尾檢定）

xbar <- 198.2; mu <- 200; s <- 3.3; n <- 10; alpha <- 0.05
t_val <- (xbar - mu) / (s / sqrt(n))
cat("t =", round(t_val, 2))
t = -1.72
t_crit <- qt(1 - alpha/2, df = n - 1)
cat("  CV = ±", round(t_crit, 3))
  CV = ± 2.262
# 95% CI
ME <- t_crit * s / sqrt(n)
cat("  95% CI: (", round(xbar - ME, 1), ",", round(xbar + ME, 1), ")")
  95% CI: ( 195.8 , 200.6 )

決策： |−1.72| < 2.262 → 不拒絕 H₀。

95% 信賴區間 (195.8, 200.6) 包含 μ = 200，確認我們無法拒絕此主張。

第二類型錯誤與檢定力

檢定力

\text{檢定力} = 1 - \beta

其中 β = P（第二類型錯誤）= 無法拒絕錯誤 H₀ 的機率

提升檢定力的方法： - 提高 α（增加靈敏度，但會增加第一類型錯誤的風險） - 增大樣本數 n（降低標準誤，最可靠的方法）

實務注意： 不拒絕 H₀ 並不能證明它為真——檢定可能只是缺乏足夠的檢定力來偵測真實的差異。

主要檢定

情境 檢定 公式
μ，σ 已知 z 檢定 z = \frac{\bar{X}-\mu}{\sigma/\sqrt{n}}
μ，σ 未知 t 檢定 t = \frac{\bar{X}-\mu}{s/\sqrt{n}}
比例 p z 檢定 z = \frac{\hat{p}-p}{\sqrt{pq/n}}

決策規則摘要

傳統法 vs. P 值法

傳統法： 將檢定值與表格中的臨界值比較

P 值法： 將計算出的 P 值與 α 比較

  • 若檢定值落在臨界區域或 P 值 \leq \alpha → 拒絕 H₀
  • 否則 → 不拒絕 H₀

信賴區間法（僅限雙尾）： 若信賴區間包含假設值 → 不拒絕 H₀；若不包含 → 拒絕 H₀
