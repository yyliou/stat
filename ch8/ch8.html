Overview

Statistical hypothesis testing is a decision-making procedure used to evaluate a claim about a population parameter.

Key Vocabulary

  • Statistical hypothesis: A conjecture about a population parameter
  • Null hypothesis (H_0): States no difference or no effect — the status quo
  • Alternative hypothesis (H_1): The research claim; what we try to support
  • Test value: A computed statistic used to decide between H_0 and H_1

Section 8-1: Steps in Hypothesis Testing

Null and Alternative Hypotheses

Note

Hypothesis Structure

  • H_0 (null hypothesis): Contains equality (=, \leq, \geq)
  • H_1 (alternative/research hypothesis): Contains inequality (\neq, <, >)
  • The claim may be in either H_0 or H_1

The direction of the alternative hypothesis determines the type of test:

H_1 contains Test type
> Right-tailed
< Left-tailed
\neq Two-tailed

Types of Errors

Key point

Type I and Type II Errors

Decision H_0 True H_0 False
Reject H_0 Type I error (\alpha) Correct decision (1 − \beta)
Do not reject H_0 Correct decision (1 − \alpha) Type II error (\beta)
  • \alpha = P(Type I error) = level of significance
  • \beta = P(Type II error)
  • Common values of \alpha: 0.10, 0.05, 0.01

Critical Region and Critical Value

Note

Key Terms

  • Critical (rejection) region: Range of values that lead to rejecting H_0
  • Noncritical region: Range of values that lead to not rejecting H_0
  • Critical value: Boundary separating the two regions

Example 8-1

Stating Hypotheses

State H_0 and H_1 for each claim:

(a) A researcher claims newborns weigh more than 8.6 lb on average.

(b) A manufacturer claims defective disks average fewer than 18 per 1000.

(c) A researcher claims background soft music changes exam scores from the mean of 73.

Example 8-1

Solution

(a) H_0: \mu = 8.6 and H_1: \mu > 8.6 (claim; right-tailed)

(b) H_0: \mu = 18 and H_1: \mu < 18 (claim; left-tailed)

(c) H_0: \mu = 73 and H_1: \mu \neq 73 (claim; two-tailed)

Five-Step Hypothesis Testing Procedure

Key point

Traditional Method

  1. State the hypotheses and identify the claim
  2. Find the critical value(s) from the appropriate table
  3. Compute the test value
  4. Make the decision (reject or do not reject H_0)
  5. Summarize the results in plain language

Section 8-2: z Test for a Mean

The z Test for a Mean

Note

Formula

z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}}

Requirements: - Population standard deviation \sigma is known - If n < 30, the population must be approximately normally distributed

Use the standard normal (z) distribution to find critical values and P-values.

Example 8-3

Days on Dealers’ Lots (Traditional)

A researcher claims that cars sit on dealers’ lots more than 29 days on average. A random sample of 30 cars gives X̄ = 30.1 days; \sigma = 3.8. Use \alpha = 0.05.

Example 8-3

Solution

Step 1: H_0: \mu = 29 and H_1: \mu > 29 (claim; right-tailed)

Step 2: CV = +1.65

Step 3: z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} = \frac{30.1 - 29}{3.8/\sqrt{30}} \approx 1.59

xbar <- 30.1; mu <- 29; sigma <- 3.8; n <- 30
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] 1.59

Step 4: Since 1.59 < 1.65 (does not fall in critical region), do not reject H_0.

Step 5: There is not enough evidence to support the claim that the mean time is greater than 29 days.

Costs of Men’s Athletic Shoes

A researcher claims the average price of men’s athletic shoes is less than $80. A sample of 36 shoes gives \bar{X} = $75, \sigma = $19.2. Use \alpha = 0.10.

Example 8-4

Solution

Step 1: H_0: \mu = 80 and H_1: \mu < 80 (claim; left-tailed)

Step 2: CV = −1.28

xbar <- 75; mu <- 80; sigma <- 19.2; n <- 36

round(z, 2)
[1] -1.56

Step 4: Since −1.56 < −1.28 (falls in critical region), reject H_0.

Step 5: There is enough evidence to support the claim that the average price is less than $80.

The P-Value Method

Note

P-Value Decision Rule

  • Compute the P-value: the probability of obtaining a test statistic at least as extreme as the one computed, assuming H_0 is true
  • If P-value \leq \alpha → reject H_0
  • If P-value > \alpha → do not reject H_0

Steps: 1. State hypotheses and identify claim 2. Compute the test value 3. Find the P-value 4. Make the decision 5. Summarize the results

Example 8-6

Problem

A researcher claims average tuition exceeds $5700. A sample of 36 schools gives X̄ = $5950, \sigma = 659. Use \alpha = 0.05.

Step 1: H_0: \mu = 5700 and H_1: \mu > 5700 (claim; right-tailed)

xbar <- 5950; mu <- 5700; sigma <- 659; n <- 36
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] 2.28
# P-value for right-tailed test
p_val <- 1 - pnorm(z)
round(p_val, 4)
[1] 0.0114

Step 4: Since P = 0.0114 < \alpha = 0.05, reject H_0.

Step 5: There is enough evidence to support the claim that average tuition exceeds 5700.

Example 8-7

Problem

A researcher claims the average wind speed in a city is 8 mph. A sample of 32 days gives X̄ = 8.2 mph, \sigma = 0.6. Use \alpha = 0.05.

Step 1: H_0: \mu = 8 (claim) and H_1: \mu \neq 8 (two-tailed)

xbar <- 8.2; mu <- 8; sigma <- 0.6; n <- 32
z <- (xbar - mu) / (sigma / sqrt(n))
round(z, 2)
[1] 1.89
# Two-tailed P-value
p_val <- 2 * (1 - pnorm(abs(z)))
round(p_val, 4)
[1] 0.0593

Step 4: Since P = 0.0593 > \alpha = 0.05, do not reject H_0.

Step 5: There is not enough evidence to reject the claim that the average wind speed is 8 mph.

Section 8-3: t Test for a Mean

The t Test for a Mean

Note

Formula

t = \frac{\bar{X} - \mu}{s / \sqrt{n}}, \quad \text{d.f.} = n - 1

Use when: - \sigma is unknown (use sample s instead) - If n < 30, the population must be approximately normally distributed

Critical values come from the t distribution with n − 1 degrees of freedom.

A hospital administrator claims the average number of infections per week is 16.3. A sample of 10 weeks gives X̄ = 17.7, s = 1.8. At \alpha = 0.05, is there enough evidence to reject the claim?

Solution

Step 2: d.f. = 9; CV = $$2.262

xbar <- 17.7; mu <- 16.3; s <- 1.8; n <- 10

[1] 2.46

[1] 2.262157

Step 4: Since 2.46 > 2.262 (falls in critical region), reject H_0.

Step 5: There is enough evidence to reject the claim that the average number of infections per week is 16.3.

Section 8-4: z Test for a Proportion

The z Test for a Proportion

Note

Formula

z = \frac{\hat{p} - p}{\sqrt{pq/n}}

where \hat{p} = X/n (sample proportion), p = hypothesized population proportion, q = 1 - p

Requirements: - Random sample - Binomial conditions satisfied - np \geq 5 and nq \geq 5

Example 8-17

Problem

A dietitian claims 60% of people try to avoid trans fats. A survey of 200 people finds 128 trying to avoid them. At \alpha = 0.05, is there enough evidence to reject the claim?

Step 1: H_0: p = 0.60 (claim) and H_1: p \neq 0.60 (two-tailed)

Step 2: CV = $$1.96

X <- 128; n <- 200; p <- 0.60; q <- 1 - p
p_hat <- X / n
z <- (p_hat - p) / sqrt(p * q / n)
cat("p-hat:", p_hat, "  z:", round(z, 2))
p-hat: 0.64   z: 1.15

Step 4: Since 1.15 is between −1.96 and +1.96, do not reject H_0.

Step 5: There is not enough evidence to reject the claim that 60% of people try to avoid trans fats.

Section 8-5: \chi^2 Test for a Variance or Standard Deviation

The Chi-Square Test for Variance

Note

Formula

\chi^2 = \frac{(n-1)s^2}{\sigma^2}, \quad \text{d.f.} = n - 1

Assumptions: - Random sample - Population is normally distributed - Observations are independent

Three test types: right-tailed (\sigma^2 > value), left-tailed (\sigma^2 < value), two-tailed (\sigma^2 \neq value)

[1] 24.99579

[1] 3.940299

Example 8-24

Variation of Test Scores (Traditional)

An instructor claims the variance in her class of 23 students (s^2 = 198) is less than the population variance (\sigma^2 = 225). At \alpha = 0.05, is there enough evidence to support the claim?

Example 8-24

Solution

Step 1: H_0: \sigma^2 = 225 and H_1: \sigma^2 < 225 (claim; left-tailed)

Step 2: d.f. = 22; CV = 12.338

Step 3: \chi^2 = \frac{(n-1)s^2}{\sigma^2} = \frac{(23-1)(198)}{225} = 19.36

n <- 23; s2 <- 198; sigma2 <- 225
chi2 <- (n - 1) * s2 / sigma2
round(chi2, 2)
[1] 19.36
qchisq(0.05, df = n - 1)  # CV (left-tailed)
[1] 12.33801

Step 4: Since 19.36 > 12.338 (does not fall in critical region), do not reject H_0.

Step 5: There is not enough evidence to support the claim that the variation in test scores is less than the population variance.

Section 8-6: Additional Topics Regarding Hypothesis Testing

Confidence Intervals and Hypothesis Testing

Note

Key Relationship

For two-tailed hypothesis tests:

  • If H_0 is rejected at \alpha → the (1 − \alpha)·100% confidence interval will NOT contain the hypothesized value
  • If H_0 is not rejected at \alpha → the (1 − \alpha)·100% confidence interval WILL contain the hypothesized value

This means a hypothesis test and confidence interval at the same level lead to the same conclusion.

Example 8-30

Sugar Production

Sugar bags are supposed to contain 5 lb. A sample of 50 bags gives X̄ = 4.6 lb, s = 0.7. At \alpha = 0.05, is there evidence the bags differ from 5 lb? Also find the 95% CI.

Example 8-30

Solution

Step 1: H_0: \mu = 5 and H_1: \mu \neq 5 (claim; two-tailed)

Step 2: d.f. = 49; CV = $$2.010

Step 3: t = \frac{\bar{X} - \mu}{s/\sqrt{n}} = \frac{4.6 - 5}{0.7/\sqrt{50}} \approx -4.04

xbar <- 4.6; mu <- 5; s <- 0.7; n <- 50; alpha <- 0.05
t_val <- (xbar - mu) / (s / sqrt(n))
cat("t =", round(t_val, 2))
t = -4.04
t_crit <- qt(1 - alpha/2, df = n - 1)
cat("  CV = ±", round(t_crit, 3))
  CV = ± 2.01
# 95% CI
ME <- t_crit * s / sqrt(n)
cat("  95% CI: (", round(xbar - ME, 1), ",", round(xbar + ME, 1), ")")
  95% CI: ( 4.4 , 4.8 )

Decision: |−4.04| > 2.010 → reject H_0. The 95% CI (4.4, 4.8) does not contain \mu = 5, confirming the rejection: there is enough evidence that the bags differ from 5 lb.

Example 8-31

Hog Weights

A researcher claims hogs fed a special diet will average 200 lb. A sample of 10 hogs gives \bar{X} = 198.2, s = 3.3. At \alpha = 0.05, can the claim be rejected? Find the 95% CI.

Example 8-31

Solution

Step 1: H_0: \mu = 200 (claim) and H_1: \mu \neq 200 (two-tailed)

xbar <- 198.2; mu <- 200; s <- 3.3; n <- 10; alpha <- 0.05
t_val <- (xbar - mu) / (s / sqrt(n))
cat("t =", round(t_val, 2))
t = -1.72
t_crit <- qt(1 - alpha/2, df = n - 1)
cat("  CV = ±", round(t_crit, 3))
  CV = ± 2.262
# 95% CI

cat("  95% CI: (", round(xbar - ME, 1), ",", round(xbar + ME, 1), ")")
  95% CI: ( 195.8 , 200.6 )

Decision: |−1.72| < 2.262 → do not reject H_0.

The 95% CI (195.8, 200.6) contains \mu = 200, confirming we cannot reject the claim.

Type II Error and the Power of a Test

Note

Power of a Test

\text{Power} = 1 - \beta

where \beta = P(Type II error) = probability of failing to reject a false H_0

Increasing power: - Increase \alpha (raises sensitivity but increases Type I error risk) - Increase sample size n (reduces standard error, most reliable method)

Practical note: Failing to reject H_0 does not prove it true — the test may simply lack sufficient power to detect a real difference.

Summary of Decision Rules

Note

Traditional vs. P-Value Method

Traditional: Compare test value to critical value from table

P-value: Compare computed P-value to \alpha

  • Reject H_0 if test value in critical region or P-value \leq \alpha
  • Do not reject H_0 otherwise

Confidence Interval Method (two-tailed only): If CI contains the hypothesized value → do not reject H_0; if it does not → reject H_0
