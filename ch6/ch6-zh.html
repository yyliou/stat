第 6-1 節：常態分佈

緒論

隨機變數可分為離散與連續兩類。第5章處理離散變數；連續變數可在任兩個給定值之間取任意值——例如成年男性的身高、老鼠的體溫、成人的膽固醇值。

許多連續變數呈鐘形分佈，稱為近似常態分佈的變數。若研究者測量 100 位成年女性的身高並繪製直方圖，接著不斷增加樣本數並縮小組距，直方圖會逐漸逼近一條平滑曲線，即常態分佈曲線（圖 6-1）。它也稱為鐘形曲線或高斯分佈曲線，以數學家 Carl Friedrich Gauss（1777–1855）為名。

沒有任何變數能完全符合常態分佈，因為常態分佈是一種理論分佈；但由於實際資料與它的偏離非常小，它仍然十分有用。

常態分佈

常態分佈

若一隨機變數的機率分佈圖形為連續、鐘形且對稱，則稱其為常態分佈，該圖形稱為常態分佈曲線。

常態分佈的數學方程式為

y = \frac{e^{-(X-\mu)^2/(2\sigma^2)}}{\sigma\sqrt{2\pi}}

其中 e \approx 2.718、\pi \approx 3.14、\mu 為母體平均數、\sigma 為母體標準差。在應用統計中，我們以查表或軟體取代直接使用此方程式。

常態分佈的性質

理論常態分佈的性質總整理

  1. 常態分佈曲線呈鐘形。
  2. 平均數、中位數與眾數三者相等，且位於分佈的中央。
  3. 常態分佈曲線為單峰（只有一個眾數）。
  4. 曲線對稱於平均數；通過中央的垂直線兩側形狀完全相同。
  5. 曲線是連續的：沒有間斷或空隙。對每一個 X 值都有對應的 Y 值。
  6. 曲線永不接觸 x 軸；無論向左右延伸多遠都不會相交，只會愈來愈接近。
  7. 常態分佈曲線下的總面積等於 1.00，即 100\%。
  8. 距平均數 1 個標準差內的面積約為 0.68，2 個標準差內約為 0.95，3 個標準差內約為 0.997。

對稱分佈與偏斜分佈

對稱分佈與偏斜分佈

  • 當資料值平均地散佈在平均數兩側時，此分佈為對稱分佈。常態分佈即為對稱分佈。
  • 當大多數資料值落在平均數右側時，分佈為負偏（左偏）分佈：平均數在中位數左側，且兩者皆在眾數左側。
  • 當大多數資料值落在平均數左側時，分佈為正偏（右偏）分佈：平均數在中位數右側，且兩者皆在眾數右側。

曲線的「尾巴」指出偏斜的方向（向右為正偏，向左為負偏）。

標準常態分佈

每個常態分佈變數都有自己的平均數與標準差，因此每個變數都需要一張面積表。為簡化此情況，統計學家使用標準常態分佈。

標準常態分佈

標準常態分佈是平均數為 0、標準差為 1 的常態分佈。

標準常態分佈的方程式為

y = \frac{e^{-z^2/2}}{\sqrt{2\pi}}

標準分數

z 分數（標準分數）公式

z = \frac{\text{數值} - \text{平均數}}{\text{標準差}} \qquad\text{或}\qquad z = \frac{X - \mu}{\sigma}

  • 此公式與 3-3 節所用者相同。
  • X 值經轉換後稱為 z 值。z 值（或 z 分數）代表某個 X 值距離平均數幾個標準差。
  • 附錄 A 的 表 A-4 提供 z 值由 -3.49 到 3.49 之標準常態曲線下面積（四位小數）。

求標準常態分佈曲線下的面積

建議採用兩步驟程序：

步驟 1 畫出常態分佈曲線並將所求面積著色。

步驟 2 在程序表中找到對應的情形，依指示計算。

程序表——求標準常態分佈曲線下的面積

  1. 某 z 值的左側： 查表找出該 z 值，直接使用表上的面積。
  2. 某 z 值的右側： 查表找出該 z 值，再以 1 減去該面積。
  3. 兩個 z 值之間： 查出兩個 z 值的面積，再相減。

三種基本題型全部整理於程序表中。

以 R 求標準常態面積

本課程以 R 取代表 A-4。程序表的三種情形對應三個 R 運算式。

常態分佈曲線作為機率分佈曲線

標準常態分佈曲線下的面積也可以視為機率，或視為具有某項特徵之母體比例。若可隨機抽取一個 z 值，抽到介於 0 與 2.00 之間的機率，就等於曲線下介於 0 與 2.00 的面積，即 0.4772。

表示機率時採用特殊記法：z 值介於 0 與 2.32 之間的機率寫成 P(0 < z < 2.32)。

注意

在連續分佈中，任一個確切 z 值的機率為 0，因為其面積是一條垂直線，理論上沒有面積。因此 P(a \leq z \leq b) = P(a < z < b)。

第 6-2 節：常態分佈的應用

常態分佈的應用

標準常態分佈曲線可用來解決各式各樣的實際問題，唯一的要求是該變數必須服從常態或近似常態分佈。解題時先將原變數轉換為標準常態變數：

z = \frac{\text{數值} - \text{平均數}}{\text{標準差}} \qquad\text{或}\qquad z = \frac{X - \mu}{\sigma}

程序表——求任一常態曲線下的面積

步驟 1 畫出常態曲線並將所求面積著色。

步驟 2 以公式 z = \dfrac{X - \mu}{\sigma} 將 X 值轉換為 z 值。

步驟 3 利用查表、計算機或軟體求出對應的面積。

在 R 中可省略轉換步驟：直接使用 pnorm(x, mean = mu, sd = sigma)。

常態性的判定

鐘形分佈只是眾多分佈形狀之一，但它極為重要，因為許多統計方法都要求資料的分佈為常態或近似常態。統計學家以多種方式檢查常態性。

檢查資料集是否為常態

  1. 直方圖。 繪製直方圖並檢視其形狀。若不近似鐘形，則資料非常態分佈。
  2. 皮爾森偏態係數（PC），又稱 皮爾森偏態指數： PC = \frac{3(\bar{X} - \text{中位數})}{s} 若指數大於或等於 +1，或小於或等於 -1，則資料顯著偏斜。
  3. 離群值。 以第3章的方法檢查離群值：低於 Q_1 或高於 Q_3 達 1.5(IQR) 以上者。即使只有一兩個離群值，也可能大幅影響常態性。

樣本平均數的分佈

除了瞭解個別資料值如何圍繞母體平均數變動之外，統計學家也想知道由同一母體抽出、大小相同的各樣本平均數如何圍繞母體平均數變動。

假設分析師抽取 30 筆網路訂單為一樣本，得平均訂單金額 1{,}180 元；再抽第二個樣本，平均值為 1{,}215 元；如此持續進行 100 個樣本。此時平均數成為一個隨機變數，而這些樣本平均數 1{,}180, 1{,}215, 1{,}164, \ldots, 1{,}232 即構成樣本平均數的抽樣分佈。

樣本平均數的抽樣分佈

樣本平均數的抽樣分佈是由某一母體中所有可能的特定大小隨機樣本所計算出的平均數所構成的分佈。

抽樣誤差

若樣本是取出放回隨機抽取，則樣本平均數多半會與母體平均數 \mu 有些差異，這些差異即由抽樣誤差造成。

抽樣誤差

抽樣誤差是樣本測量值與對應母體測量值之間的差異，肇因於樣本並非母體的完美代表。

樣本平均數分佈的性質

  1. 樣本平均數的平均數等於母體平均數。
  2. 樣本平均數的標準差小於母體標準差，且等於母體標準差除以樣本大小的平方根。

平均數的標準誤

平均數的標準誤

若自同一母體取出放回抽取所有大小為 n 的樣本，則樣本平均數的平均數 \mu_{\bar{X}} 等於母體平均數 \mu；樣本平均數的標準差 \sigma_{\bar{X}} 等於 \sigma/\sqrt{n}。樣本平均數的標準差稱為平均數的標準誤。

樣本平均數的平均數與標準誤

\mu_{\bar{X}} = \mu \qquad\qquad \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}

中央極限定理

樣本平均數抽樣分佈的第三個性質與分佈的形狀有關，由中央極限定理說明。

中央極限定理

當樣本大小 n 無限制地增大時，自平均數為 \mu、標準差為 \sigma 的母體取出放回抽樣所得之樣本平均數，其分佈形狀將趨近常態分佈。此分佈的平均數為 \mu，標準差為 \sigma/\sqrt{n}。

中央極限定理的 z 值

z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}}

由於使用的是平均數而非個別資料值，分母必須調整為樣本平均數的標準差。

兩項必記要點

中央極限定理的適用時機

  1. 當原變數服從常態分佈時，樣本平均數的分佈對任何樣本大小 n 都是常態分佈。
  2. 當原變數的分佈非常態時，需要樣本大小達 30 以上，才能以常態分佈近似樣本平均數的分佈。樣本愈大，近似愈佳。

在 R 中： 使用 pnorm(xbar, mean = mu, sd = sigma / sqrt(n))。

第 6-4 節：二項分佈的常態近似

為何使用常態近似？

當 n 很大（例如 100）時，二項分佈的計算以手算過於困難，故改用常態分佈求解。回顧第5章，二項分佈具有下列特性：

  1. 必須有固定的試驗次數。
  2. 各次試驗的結果必須互相獨立。
  3. 每次試驗只能有兩種結果，或可化簡為兩種結果。
  4. 每次試驗的成功機率必須維持不變。

當 p 接近 0.5 且 n 增大時，二項分佈的形狀愈來愈像常態分佈。但當 p 接近 0 或 1 且 n 相對較小時，常態近似並不準確。

np \geq 5 與 nq \geq 5 的條件

經驗法則

唯有當 n \cdot p 與 n \cdot q 兩者皆大於或等於 5 時，才應使用常態近似，其中 q = 1 - p。

此外，\mu = n \cdot p，\sigma = \sqrt{n \cdot p \cdot q}。

例如 p = 0.3、n = 10 時，np = 3，不應使用常態分佈；若 p = 0.5、n = 10，則 np = nq = 5，可以使用。

連續性修正

連續性修正

連續性修正是以連續分佈近似離散分佈時所採用的修正。

連續性修正的意思是：對任一特定的 X 值（例如 8），必須使用二項分佈中該值的組界（此例為 7.5 到 8.5）。P(X = 8) 修正為 P(7.5 < X < 8.5)；P(X \leq 7) 修正為 P(X < 7.5)；P(X \geq 3) 修正為 P(X > 2.5)。

表 6-2

表 6-2 二項分佈常態近似總整理

欲求（二項） 改用（常態）
1. P(X = a) P(a - 0.5 < X < a + 0.5)
2. P(X \geq a) P(X > a - 0.5)
3. P(X > a) P(X > a + 0.5)
4. P(X \leq a) P(X < a + 0.5)
5. P(X < a) P(X < a - 0.5)

所有情形皆有 \mu = n \cdot p、\sigma = \sqrt{n \cdot p \cdot q}、n \cdot p \geq 5 且 n \cdot q \geq 5。

某跨境電商平台的買家中，有 30\% 選擇超商取貨而非宅配到府。若隨機選取 150 位買家，求其中恰有 52 位選擇超商取貨的機率。（模擬資料）

範例 6-16

解題

此處 p = 0.30、q = 0.70、n = 150。

步驟 1 np = (150)(0.30) = 45，nq = (150)(0.70) = 105。因 np \geq 5 且 nq \geq 5，可使用常態分佈。

步驟 2 \mu = np = 45，\sigma = \sqrt{npq} = \sqrt{(150)(0.30)(0.70)} = \sqrt{31.5} \approx 5.61

步驟 3 P(X = 52)

步驟 4 依表 6-2 的第 1 種情形：P(51.5 < X < 52.5)（圖 6-40）。

步驟 5 z_1 = \dfrac{51.5 - 45}{5.61} \approx 1.16，z_2 = \dfrac{52.5 - 45}{5.61} \approx 1.34

步驟 6 z_1 與 z_2 之間的面積為 0.0327，約 3.27\%。

重要公式

常態分佈

常態分佈與標準常態分佈的方程式： y = \frac{e^{-(X-\mu)^2/(2\sigma^2)}}{\sigma\sqrt{2\pi}} \qquad\qquad y = \frac{e^{-z^2/2}}{\sqrt{2\pi}}

z 分數（標準分數）公式，以及求特定資料值的公式： z = \frac{X - \mu}{\sigma} \qquad\qquad X = z \cdot \sigma + \mu

重要公式

樣本平均數與二項分佈的常態近似

樣本平均數的平均數與平均數的標準誤： \mu_{\bar{X}} = \mu \qquad\qquad \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}}

中央極限定理的 z 值，以及有限母體校正因子： z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \qquad\qquad \sqrt{\frac{N-n}{N-1}}

二項分佈的平均數與標準差： \mu = n \cdot p \qquad\qquad \sigma = \sqrt{n \cdot p \cdot q}

皮爾森偏態係數：PC = \dfrac{3(\bar{X} - \text{中位數})}{s}

重點整理

重點

  • 常態分佈為連續、鐘形、單峰且對稱；其平均數、中位數與眾數相等，曲線下總面積為 1，且曲線永不接觸 x 軸
  • 距平均數 1、2、3 個標準差內的面積分別約為 68\%、95\%、99.7\%
  • 標準常態分佈的 \mu = 0、\sigma = 1；任何常態變數可用 z = \dfrac{X-\mu}{\sigma} 轉換，亦可用 X = z\sigma + \mu 反求資料值
  • 標準常態曲線下的面積即為機率；因分佈為連續，故 P(a \leq z \leq b) = P(a < z < b)
  • 常態性的檢查方式包括直方圖、皮爾森偏態指數 PC = \dfrac{3(\bar{X}-\text{中位數})}{s}（PC \geq +1 或 PC \leq -1 即為顯著偏斜）、離群值檢查與常態分位圖

重點整理

重點

  • 樣本平均數的抽樣分佈由所有可能之特定大小樣本的平均數構成；\mu_{\bar{X}} = \mu，標準誤為 \sigma_{\bar{X}} = \sigma/\sqrt{n}
  • 中央極限定理指出，當 n 無限制增大時，樣本平均數的分佈趨近常態分佈——母體為常態時對任何 n 皆成立，否則需 n \geq 30
  • 自有限母體不放回抽取超過母體 5\% 的樣本時，需使用有限母體校正因子 \sqrt{\dfrac{N-n}{N-1}}
  • 二項分佈的常態近似須滿足 np \geq 5 且 nq \geq 5，其中 \mu = np、\sigma = \sqrt{npq}
  • 以連續分佈近似離散分佈時，務必套用連續性修正（\pm 0.5）
