本章概覽

為何要用 ANOVA？

比較三個或三個以上組別平均數時，使用多次 t 檢定會有問題：

  • 每增加一次比較，就會使第一型錯誤率膨脹
  • 有 k 個組別，需要 \binom{k}{2} 次兩兩比較
  • F 檢定在單次檢定中同時比較所有平均數

涵蓋主題：

  • 第12-1節： 單因子變異數分析（One-Way ANOVA）
  • 第12-2節： 事後檢定 — Scheffé 法與 Tukey 法
  • 第12-3節： 二因子變異數分析（Two-Way ANOVA）

歷史背景

ANOVA 的起源

變異數分析方法由 R. A. Fisher 在1920年代初期發展出來。

ANOVA 利用變異數對平均數進行推論 — 故得名「變異數分析」。

第12-1節：單因子變異數分析

為何不使用多次 t 檢定？

避免多次 t 檢定的三個原因

  1. 忽略其他組： 每次兩兩比較都忽略了剩餘的組別
  2. 第一型錯誤率膨脹： 比較次數越多，誤判顯著的機率越高
  3. 檢定次數暴增： 3個平均數 → 3次；5個平均數 → 10次；10個平均數 → 45次

F 檢定同時比較所有平均數，解決上述三個問題。

單因子 ANOVA 的假設

假設條件

  1. 每個母體必須服從常態分配或近似常態分配
  2. 所有樣本必須相互獨立
  3. 所有母體的變異數必須相等（變異數同質性）

ANOVA 的邏輯

兩種變異數估計量

估計量 衡量什麼
組間變異數 (s_B^2) 樣本平均數之間的變異
組內變異數 (s_W^2) 每組內部的變異（合併）
  • 若 H_0 為真：s_B^2 \approx s_W^2，因此 F \approx 1
  • 若 H_0 為假：s_B^2 \gg s_W^2，因此 F \gg 1

F = \frac{s_B^2}{s_W^2}

比較平均數的 F 檢定永遠是右尾。

假設與自由度

ANOVA 假設

H_0: \mu_1 = \mu_2 = \cdots = \mu_k H_1: \text{至少有一個平均數與其他不同}

自由度

d.f.N. = k - 1 \qquad d.f.D. = N - k

其中 k = 組數，N = n_1 + n_2 + \cdots + n_k

ANOVA 計算公式

逐步計算程序

步驟一： 求每個樣本的平均數和變異數：(\bar{X}_1, s_1^2), \ldots, (\bar{X}_k, s_k^2)

步驟二： 總平均數：\bar{X}_{GM} = \dfrac{\sum X}{N}

步驟三： 組間變異數：s_B^2 = \dfrac{\sum n_i(\bar{X}_i - \bar{X}_{GM})^2}{k-1}

步驟四： 組內變異數：s_W^2 = \dfrac{\sum (n_i - 1)s_i^2}{\sum (n_i - 1)}

步驟五： F = \dfrac{s_B^2}{s_W^2}

ANOVA 摘要表

標準摘要表格式

來源 SS 自由度 MS F
組間（處理） SSB k-1 MSB = SSB/(k-1) MSB/MSW
組內（誤差） SSW N-k MSW = SSW/(N-k)
總計 SST N-1

其中： - SSB = \sum n_i(\bar{X}_i - \bar{X}_{GM})^2 - SSW = \sum (n_i - 1)s_i^2

第12-2節：Scheffé 檢定與 Tukey 檢定

事後檢定：概觀

為何需要事後檢定？

當 F 檢定拒絕 H_0 時，我們知道至少有一個平均數不同，但不知道是哪幾個不同。

事後檢定在 ANOVA 之後進行所有的兩兩比較：

檢定 最適用時機
Scheffé 樣本數不等時；最保守
Tukey 樣本數相等時；兩兩比較更有效力

一般原則： 當 n_i = n_j 時用 Tukey；當樣本數不等時用 Scheffé。

Scheffé 檢定

Scheffé 檢定公式

F_S = \frac{(\bar{X}_i - \bar{X}_j)^2}{s_W^2\left(\dfrac{1}{n_i} + \dfrac{1}{n_j}\right)}

Scheffé 的臨界值： F' = (k-1) \times C.V._{\text{ANOVA}}

若 F_S > F'，則拒絕該對的 H_0。

範例 12-3

血壓資料的 Scheffé 檢定

使用 Scheffé 檢定，判斷範例 12-1 中哪些平均數對在 \alpha = 0.05 下有顯著差異。

已知：\bar{X}_1=11.8，\bar{X}_2=3.8，\bar{X}_3=7.6，s_W^2=8.73，各組 n_i=5。

範例 12-3

解題

數學解法

臨界值： F' = (k-1)(C.V.) = (3-1)(3.89) = 7.78

a. \bar{X}_1 vs \bar{X}_2： F_S = \frac{(11.8 - 3.8)^2}{8.73(1/5 + 1/5)} = \frac{64}{3.492} = 18.33 \quad \checkmark > 7.78

b. \bar{X}_2 vs \bar{X}_3： F_S = \frac{(3.8 - 7.6)^2}{8.73(1/5 + 1/5)} = \frac{14.44}{3.492} = 4.14 \quad \text{不顯著}

c. \bar{X}_1 vs \bar{X}_3： F_S = \frac{(11.8 - 7.6)^2}{8.73(1/5 + 1/5)} = \frac{17.64}{3.492} = 5.05 \quad \text{不顯著}

結論： 只有藥物 vs. 運動（\bar{X}_1 vs \bar{X}_2）有顯著差異。

範例 12-3

解題

R 程式

# 使用 agricolae 套件的 Scheffé 檢定（或手動計算）
# 手動 Scheffe 檢定
scheffe_fs <- function(x1_bar, x2_bar, sw2, n1, n2) {
  (x1_bar - x2_bar)^2 / (sw2 * (1/n1 + 1/n2))
}

sw2 <- 8.73
cv_scheffe <- (3 - 1) * 3.89  # F' = 7.78

cat("Critical value F' =", cv_scheffe, "\n\n")
Critical value F' = 7.78 
pairs <- list(
  c("Medication vs Exercise", 11.8, 3.8),
  c("Exercise vs Diet",       3.8,  7.6),
  c("Medication vs Diet",     11.8, 7.6)
)

for (p in pairs) {
  fs <- scheffe_fs(as.numeric(p[2]), as.numeric(p[3]), sw2, 5, 5)
  sig <- ifelse(fs > cv_scheffe, "SIGNIFICANT", "not significant")
  cat(p[1], ": Fs =", round(fs, 2), "->", sig, "\n")
}
Medication vs Exercise : Fs = 18.33 -> SIGNIFICANT 
Exercise vs Diet : Fs = 4.14 -> not significant 
Medication vs Diet : Fs = 5.05 -> not significant

Tukey 檢定

Tukey 檢定公式

當所有樣本數相等時使用：

q = \frac{\bar{X}_i - \bar{X}_j}{\sqrt{s_W^2 / n}}

將 |q| 與 Tukey 表（表 N）中的臨界值比較：

  • 列：\nu = s_W^2 的自由度（= N - k）
  • 欄：k = 組數

若 |q| > 臨界值，則拒絕該對的 H_0。

範例 12-4

血壓資料的 Tukey 檢定

使用 Tukey 檢定，判斷範例 12-1 中哪些平均數對在 \alpha = 0.05 下有顯著差異。

\bar{X}_1=11.8，\bar{X}_2=3.8，\bar{X}_3=7.6，s_W^2=8.73，n=5

範例 12-4

解題

數學解法

\sqrt{s_W^2/n} = \sqrt{8.73/5} = \sqrt{1.746} = 1.321

臨界值： k=3，d.f.=12，\alpha=0.05 → q_{crit} = 3.77（查 Tukey 表）

a. \bar{X}_1 vs \bar{X}_2： q = \frac{11.8 - 3.8}{1.321} = \frac{8}{1.321} = 6.06 \quad \checkmark > 3.77

b. \bar{X}_1 vs \bar{X}_3： q = \frac{11.8 - 7.6}{1.321} = \frac{4.2}{1.321} = 3.18 \quad \text{不顯著}

c. \bar{X}_2 vs \bar{X}_3： q = \frac{|3.8 - 7.6|}{1.321} = \frac{3.8}{1.321} = 2.88 \quad \text{不顯著}

結論： 只有藥物 vs. 運動有顯著差異 — 與 Scheffé 結果一致。

Scheffé vs. Tukey：比較

各檢定的適用時機

特性 Scheffé Tukey
樣本數 不等或相等 必須相等
效力 較低（保守） 兩兩比較較高
比較類型 兩兩比較及組合 僅限兩兩比較
建議 n_i 不等時 n_i 相等時

重要提示： 當 F 檢定拒絕 H_0 時，事後檢定有時可能找不到任何顯著的配對 — 差異可能在於多個平均數的組合，而非單一配對。

第12-3節：二因子變異數分析

二因子 ANOVA 簡介

單因子 ANOVA 的延伸

單因子 ANOVA： 一個自變數（因子）

二因子 ANOVA： 兩個自變數（因子）

二因子 ANOVA 的優點： - 在單一實驗中同時檢定兩個因子 - 檢定兩個因子之間的交互作用效果 - 比兩次單獨的單因子 ANOVA 更有效率

二因子 ANOVA：設計結構

因子設計術語

  • 因子 A 有 a 個水準
  • 因子 B 有 b 個水準
  • 每格有 n 位受試者（必須相等）
  • 受試者總數 = abn

2 \times 2 設計每個因子各有2個水準 → 4個處理組。

例如：植物肥料類型（A1, A2）\times 土壤類型（I, II）→ 4組

二因子 ANOVA：三個假設

假設

1. 交互作用效果： H_0: \text{因子 A 與因子 B 之間無交互作用} H_1: \text{A 與 B 之間有交互作用}

2. 因子 A 的主效果： H_0: \text{A 各水準的平均數無差異} H_1: \text{至少有一個 A 的平均數不同}

3. 因子 B 的主效果： H_0: \text{B 各水準的平均數無差異} H_1: \text{至少有一個 B 的平均數不同}

二因子 ANOVA：假設條件

假設條件

  1. 母體必須服從常態分配或近似常態分配
  2. 所有樣本必須相互獨立
  3. 各組母體變異數必須相等
  4. 各組樣本數必須相等（每格的 n 相同）

二因子 ANOVA：摘要表

一般 ANOVA 表

來源 SS 自由度 MS F
因子 A SSA a-1 MSA F_A = MSA/MSW
因子 B SSB b-1 MSB F_B = MSB/MSW
交互作用 A \times B SS(A \times B) (a-1)(b-1) MS(A \times B) F_{A \times B} = MS(A \times B)/MSW
組內（誤差） SSW ab(n-1) MSW
總計 SST abn-1

詮釋交互作用效果

交互作用的類型

圖形樣式 交互作用類型 詮釋
線條平行 無交互作用 可獨立詮釋主效果
線條交叉 非次序性交互作用 不得獨立詮釋主效果
線條發散但不交叉 次序性交互作用 仍可詮釋主效果

規則： 當交互作用 F 檢定顯著時： - 查看交互作用圖 - 若線條交叉 → 非次序性交互作用 → 僅在考量交互作用的前提下詮釋 - 若線條不交叉 → 次序性交互作用 → 可詮釋主效果

第12章摘要

重點摘要

第12-1節 — 單因子 ANOVA： - F 檢定同時比較3個以上的平均數 - F = s_B^2 / s_W^2；若 F > F_{crit} 則拒絕 H_0（右尾） - 自由度：d.f.N. = k-1，d.f.D. = N-k

第12-2節 — 事後檢定： - Scheffé：彈性較高，適用於 n 不等的情況；較保守 - Tukey：在 n 相等時，兩兩比較效力較強

第12-3節 — 二因子 ANOVA： - 同時檢定兩個因子及其交互作用 - 若交互作用顯著，不得獨立詮釋主效果 - 交互作用圖揭示關係的本質
