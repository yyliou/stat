第 9 章概述

研究者通常需要比較兩個群組，而非將單一參數與固定值進行檢定。

本章涵蓋以下情境的假設檢定與信賴區間：

  • 兩個均值（σ 已知時用 z 檢定；σ 未知時用 t 檢定；相依樣本用配對 t 檢定）
  • 兩個比例（z 檢定）
  • 兩個變異數（F 檢定）

第 9-1 節：使用 z 檢定來檢定兩均值之差

重要概念——兩個獨立樣本

Note

當一組受試者與另一組受試者無任何關聯時，稱兩個樣本為獨立樣本。

z 檢定（兩均值）的要求條件：

  • 兩個樣本均為隨機且獨立
  • 母體標準差 σ₁ 與 σ₂ 已知
  • 若 n < 30，母體應近似常態分配

公式：兩均值的 z 檢定

Note

z = \frac{(\bar{X}_1 - \bar{X}_2) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}}

在 H_0: \mu_1 = \mu_2 的假設下，可簡化為：

z = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}}

例題 9-1：飯店房價

問題

某旅遊業者聲稱紐奧良的飯店房價平均高於鳳凰城。各城市抽取 50 家飯店的樣本，結果如下：

城市 \bar{X} \sigma n
紐奧良 $88.42 $5.62 50
鳳凰城 $80.61 $4.83 50

在 α = 0.05 下檢定此主張。

例題 9-1：解題步驟（數學）

步驟 1： H₀：μ₁ = μ₂    H₁：μ₁ > μ₂（主張）——右尾檢定

步驟 2： CV = +1.645（α = 0.05，右尾檢定）

步驟 3： z = \frac{88.42 - 80.61}{\sqrt{\dfrac{5.62^2}{50} + \dfrac{4.83^2}{50}}} = \frac{7.81}{\sqrt{0.6317 + 0.4674}} = \frac{7.81}{1.048} \approx 7.45

步驟 4： 7.45 > 1.645 → 拒絕 H₀

步驟 5： 有足夠證據支持紐奧良飯店房價高於鳳凰城的主張。

例題 9-1：解題步驟（R）

x1 <- 88.42; x2 <- 80.61
s1 <- 5.62;  s2 <- 4.83
n1 <- 50;    n2 <- 50

z <- (x1 - x2) / sqrt(s1^2/n1 + s2^2/n2)
cv <- qnorm(0.95)
p_val <- pnorm(z, lower.tail = FALSE)

cat("z =", round(z, 4), "\n")
z = 7.4524 
cat("臨界值 =", round(cv, 3), "\n")
臨界值 = 1.645 
cat("P 值 =", round(p_val, 6), "\n")
P 值 = 0 
cat("決策:", ifelse(z > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 拒絕 H0

例題 9-2：大學運動項目選擇（P 值法）

問題

某研究者假設男大學生在線上能選擇的運動項目多於女大學生。各抽取 50 所大學的樣本，結果如下：

  • 男生：\bar{X}_1 = 8.6，\sigma_1 = 3.3，n_1 = 50
  • 女生：\bar{X}_2 = 7.9，\sigma_2 = 3.3，n_2 = 50

在 α = 0.10 下，使用 P 值法檢定此主張。

例題 9-2：解題步驟（數學）

步驟 1： H₀：μ₁ = μ₂    H₁：μ₁ > μ₂（主張）——右尾檢定

步驟 2： α = 0.10

步驟 3： z = \frac{8.6 - 7.9}{\sqrt{\dfrac{3.3^2}{50} + \dfrac{3.3^2}{50}}} = \frac{0.7}{\sqrt{0.2178 + 0.2178}} = \frac{0.7}{0.6600} \approx 1.06

P 值 = P(z > 1.06) = 1 − 0.8554 = 0.1446

步驟 4： 0.1446 > 0.10 → 不拒絕 H₀

步驟 5： 沒有足夠證據支持男生能選擇更多線上運動項目的主張。

例題 9-2：解題步驟（R）

x1 <- 8.6; x2 <- 7.9
s1 <- 3.3; s2 <- 3.3
n1 <- 50;  n2 <- 50

z <- (x1 - x2) / sqrt(s1^2/n1 + s2^2/n2)
p_val <- pnorm(z, lower.tail = FALSE)

cat("z =", round(z, 4), "\n")
z = 1.0606 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.1444 
cat("決策:", ifelse(p_val < 0.10, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 不拒絕 H0

μ₁ − μ₂ 的信賴區間（σ 已知）

Note

(\bar{X}_1 - \bar{X}_2) - z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}} < \mu_1-\mu_2 < (\bar{X}_1 - \bar{X}_2) + z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}

例題 9-3：飯店房價的 95% 信賴區間

問題

使用例題 9-1的資料，求 μ₁ − μ₂ 的 95% 信賴區間。

解答：

z_{\alpha/2} = 1.96，\bar{X}_1 - \bar{X}_2 = 7.81

7.81 \pm 1.96\sqrt{\frac{5.62^2}{50}+\frac{4.83^2}{50}} = 7.81 \pm 1.96(1.048) = 7.81 \pm 2.054

\boxed{5.76 < \mu_1 - \mu_2 < 9.86}

由於區間不包含 0，表示兩者存在顯著差異。

例題 9-3：解題步驟（R）

x1 <- 88.42; x2 <- 80.61
s1 <- 5.62;  s2 <- 4.83
n1 <- 50;    n2 <- 50

diff <- x1 - x2
se   <- sqrt(s1^2/n1 + s2^2/n2)
moe  <- qnorm(0.975) * se

cat("95% CI: (", round(diff - moe, 2), ",", round(diff + moe, 2), ")\n")
95% CI: ( 5.76 , 9.86 )

第 9-2 節：使用 t 檢定來檢定兩個獨立樣本均值之差

何時使用 t 檢定（兩個獨立均值）

Note

以下情況使用 t 檢定：

  • 樣本為獨立且隨機
  • 母體標準差 σ₁ 與 σ₂ 未知
  • 兩個母體均近似常態分配

t = \frac{(\bar{X}_1 - \bar{X}_2) - (\mu_1 - \mu_2)}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}

自由度： \text{自由度} = \min(n_1-1,\; n_2-1) （保守方法）

例題 9-4：農場面積

問題

某研究者想確定印第安納郡與格林郡的農場面積是否不同。隨機抽樣結果如下：

印第安納郡 格林郡
\bar{X} 191 英畝 199 英畝
s 38 12
n 8 10

在 α = 0.05 下，檢定兩者均值是否不同。

例題 9-4：解題步驟（數學）

步驟 1： H₀：μ₁ = μ₂    H₁：μ₁ ≠ μ₂（主張）——雙尾檢定

步驟 2： 自由度 = min(8−1, 10−1) = 7；CV = ±2.365

步驟 3： t = \frac{191 - 199}{\sqrt{\dfrac{38^2}{8} + \dfrac{12^2}{10}}} = \frac{-8}{\sqrt{180.5 + 14.4}} = \frac{-8}{\sqrt{194.9}} \approx -0.573

步驟 4： |−0.573| < 2.365 → 不拒絕 H₀

步驟 5： 沒有足夠證據得出兩郡農場面積不同的結論。

例題 9-4：解題步驟（R）

x1 <- 191; x2 <- 199
s1 <- 38;  s2 <- 12
n1 <- 8;   n2 <- 10

t_stat <- (x1 - x2) / sqrt(s1^2/n1 + s2^2/n2)
df     <- min(n1 - 1, n2 - 1)
cv     <- qt(0.975, df)
p_val  <- 2 * pt(abs(t_stat), df, lower.tail = FALSE)

cat("t =", round(t_stat, 4), "\n")
t = -0.573 
cat("自由度 =", df, "\n")
自由度 = 7 
cat("臨界值 =", round(cv, 3), "\n")
臨界值 = 2.365 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.5845 
cat("決策:", ifelse(abs(t_stat) > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 不拒絕 H0

μ₁ − μ₂ 的信賴區間（σ 未知）

Note

(\bar{X}_1 - \bar{X}_2) - t_{\alpha/2}\sqrt{\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}} < \mu_1-\mu_2 < (\bar{X}_1 - \bar{X}_2) + t_{\alpha/2}\sqrt{\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}}

其中 \text{自由度} = \min(n_1-1,\; n_2-1)

例題 9-5：農場面積的 95% 信賴區間

問題

使用例題 9-4的資料，建構 μ₁ − μ₂ 的 95% 信賴區間。

解答： 自由度 = 7；t_{0.025, 7} = 2.365

-8 \pm 2.365\sqrt{\frac{38^2}{8}+\frac{12^2}{10}} = -8 \pm 2.365(13.96) = -8 \pm 33.02

\boxed{-41.02 < \mu_1 - \mu_2 < 25.02}

由於 0 在區間內，表示無顯著差異。

例題 9-5：解題步驟（R）

x1 <- 191; x2 <- 199
s1 <- 38;  s2 <- 12
n1 <- 8;   n2 <- 10

diff <- x1 - x2
se   <- sqrt(s1^2/n1 + s2^2/n2)
df   <- min(n1 - 1, n2 - 1)
moe  <- qt(0.975, df) * se

cat("95% CI: (", round(diff - moe, 2), ",", round(diff + moe, 2), ")\n")
95% CI: ( -41.01 , 25.01 )

第 9-3 節：相依樣本的兩均值差異檢定

相依樣本（配對資料）

Note

以下情況稱為相依（配對）樣本：

  • 相同受試者被測量兩次（前測／後測）
  • 受試者依某特性進行配對

程序： 對每對資料計算差值 D = X_1 - X_2，然後檢定：

t = \frac{\bar{D} - \mu_D}{s_D / \sqrt{n}}, \quad \text{自由度} = n - 1

其中 \bar{D} = \dfrac{\sum D}{n} 且 s_D = \sqrt{\dfrac{n\sum D^2 - (\sum D)^2}{n(n-1)}}

例題 9-6：銀行存款

問題

某銀行經理聲稱過去 3 年存款已減少。以下為 9 家銀行的資料（單位：百萬元）：

銀行 3 年前 今日 D
1 1.2 1.8 −0.6
2 5.6 5.7 −0.1
3 7.1 8.2 −1.1
4 2.3 2.1 0.2
5 4.0 5.3 −1.3
6 2.4 3.1 −0.7
7 1.7 1.8 −0.1
8 0.4 1.9 −1.5
9 0.9 1.5 −0.6

在 α = 0.05 下，檢定此主張。

例題 9-6：解題步驟（數學）

步驟 1： H₀：μ_D = 0    H₁：μ_D < 0（主張）——左尾檢定

步驟 2： 自由度 = 8；CV = −1.860

步驟 3： D 值：−0.6、−0.1、−1.1、0.2、−1.3、−0.7、−0.1、−1.5、−0.6

\bar{D} = \frac{-9.73}{9} \approx -1.081

ΣD² = 0.36+0.01+1.21+0.04+1.69+0.49+0.01+2.25+0.36 = 6.42

使用教科書數值：\bar{D} = -1.081，s_D = 1.937

t = \frac{-1.081 - 0}{1.937/\sqrt{9}} = \frac{-1.081}{0.646} \approx -1.67

步驟 4： −1.67 > −1.860 → 不拒絕 H₀

步驟 5： 沒有足夠證據支持存款已減少的主張。

例題 9-6：解題步驟（R）

before <- c(1.2, 5.6, 7.1, 2.3, 4.0, 2.4, 1.7, 0.4, 0.9)
today  <- c(1.8, 5.7, 8.2, 2.1, 5.3, 3.1, 1.8, 1.9, 1.5)

D    <- before - today
Dbar <- mean(D)
sD   <- sd(D)
n    <- length(D)
t_stat <- Dbar / (sD / sqrt(n))
df     <- n - 1
cv     <- qt(0.05, df)

cat("D-bar =", round(Dbar, 4), "\n")
D-bar = -0.6444 
cat("sD =", round(sD, 4), "\n")
sD = 0.579 
cat("t =", round(t_stat, 4), "\n")
t = -3.3389 
cat("臨界值 =", round(cv, 3), "\n")
臨界值 = -1.86 
cat("決策:", ifelse(t_stat < cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 拒絕 H0

例題 9-7：膽固醇值

問題

某研究者聲稱礦物質補充劑會影響膽固醇值。六位受試者在服用補充劑前後分別進行檢測：

受試者 服用前 服用後 D
1 210 190 20
2 235 170 65
3 208 210 −2
4 190 188 2
5 172 173 −1
6 244 228 16

在 α = 0.10 下，檢定膽固醇值是否改變的主張。

例題 9-7：解題步驟（數學）

步驟 1： H₀：μ_D = 0    H₁：μ_D ≠ 0（主張）——雙尾檢定

步驟 2： 自由度 = 5；CV = ±2.015

步驟 3： ΣD = 100，\bar{D} = 100/6 = 16.7

ΣD² = 400 + 4225 + 4 + 4 + 1 + 256 = 4890

s_D = \sqrt{\frac{6(4890) - 100^2}{6(5)}} = \sqrt{\frac{29340 - 10000}{30}} = \sqrt{644.67} \approx 25.4

t = \frac{16.7}{25.4/\sqrt{6}} = \frac{16.7}{10.37} \approx 1.610

步驟 4： |1.610| < 2.015 → 不拒絕 H₀

步驟 5： 沒有足夠證據支持補充劑影響膽固醇值的主張。

例題 9-7：解題步驟（R）

before <- c(210, 235, 208, 190, 172, 244)
after  <- c(190, 170, 210, 188, 173, 228)

D      <- before - after
Dbar   <- mean(D)
sD     <- sd(D)
n      <- length(D)
t_stat <- Dbar / (sD / sqrt(n))
df     <- n - 1
cv     <- qt(0.95, df)
p_val  <- 2 * pt(abs(t_stat), df, lower.tail = FALSE)

cat("D-bar =", round(Dbar, 4), "\n")
D-bar = 16.6667 
cat("sD =", round(sD, 4), "\n")
sD = 25.3903 
cat("t =", round(t_stat, 4), "\n")
t = 1.6079 
cat("臨界值 =", round(cv, 3), "\n")
臨界值 = 2.015 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.1688 
cat("決策:", ifelse(abs(t_stat) > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 不拒絕 H0

μ_D 的信賴區間（相依樣本）

Note

\bar{D} - t_{\alpha/2}\frac{s_D}{\sqrt{n}} < \mu_D < \bar{D} + t_{\alpha/2}\frac{s_D}{\sqrt{n}}

其中 \text{自由度} = n - 1

例題 9-8：膽固醇變化的 90% 信賴區間

問題

使用例題 9-7 的資料，求 μ_D 的 90% 信賴區間。

解答： 自由度 = 5；t_{0.05, 5} = 2.015

16.7 \pm 2.015 \cdot \frac{25.4}{\sqrt{6}} = 16.7 \pm 2.015(10.37) = 16.7 \pm 20.9

\boxed{-4.19 < \mu_D < 37.59}

由於區間包含 0，無法得出膽固醇值有顯著改變的結論。

例題 9-8：解題步驟（R）

before <- c(210, 235, 208, 190, 172, 244)
after  <- c(190, 170, 210, 188, 173, 228)

D    <- before - after
Dbar <- mean(D)
sD   <- sd(D)
n    <- length(D)
df   <- n - 1
moe  <- qt(0.95, df) * sD / sqrt(n)

cat("90% CI: (", round(Dbar - moe, 2), ",", round(Dbar + moe, 2), ")\n")
90% CI: ( -4.22 , 37.55 )

第 9-4 節：兩比例差異的檢定

兩比例的 z 檢定

Note

比例的合併估計量： \bar{p} = \frac{X_1 + X_2}{n_1 + n_2}, \quad \bar{q} = 1 - \bar{p}

檢定統計量： z = \frac{(\hat{p}_1 - \hat{p}_2) - (p_1 - p_2)}{\sqrt{\bar{p}\bar{q}\left(\dfrac{1}{n_1}+\dfrac{1}{n_2}\right)}}

要求條件： n_1\hat{p}_1、n_1\hat{q}_1、n_2\hat{p}_2、n_2\hat{q}_2 均 ≥ 5

例題 9-9：療養院的疫苗接種率

問題

某研究者想確定小型與大型療養院的流感疫苗接種率是否相同。在 α = 0.05 下，檢定此主張。

小型 大型
已接種居民數 12 17
抽樣總人數 34 24

例題 9-9：解題步驟（數學）

步驟 1： H₀：p₁ = p₂（主張）   H₁：p₁ ≠ p₂——雙尾檢定

步驟 2： CV = ±1.96

步驟 3： \hat{p}_1 = 12/34 = 0.353；\hat{p}_2 = 17/24 = 0.708

\bar{p} = \frac{12+17}{34+24} = \frac{29}{58} = 0.5；\bar{q} = 0.5

z = \frac{0.353 - 0.708}{\sqrt{0.5 \times 0.5\left(\frac{1}{34}+\frac{1}{24}\right)}} = \frac{-0.355}{\sqrt{0.25(0.0706)}} = \frac{-0.355}{0.1328} \approx -2.67

步驟 4： |−2.67| > 1.96 → 拒絕 H₀

步驟 5： 有足夠證據拒絕小型與大型療養院疫苗接種率相同的主張。

例題 9-9：解題步驟（R）

x1 <- 12; n1 <- 34
x2 <- 17; n2 <- 24

phat1 <- x1/n1; phat2 <- x2/n2
pbar  <- (x1 + x2)/(n1 + n2)
qbar  <- 1 - pbar

z     <- (phat1 - phat2) / sqrt(pbar * qbar * (1/n1 + 1/n2))
cv    <- qnorm(0.975)
p_val <- 2 * pnorm(abs(z), lower.tail = FALSE)

cat("p-hat1 =", round(phat1, 4), " p-hat2 =", round(phat2, 4), "\n")
p-hat1 = 0.3529  p-hat2 = 0.7083 
cat("p-bar =", round(pbar, 4), "\n")
p-bar = 0.5 
cat("z =", round(z, 4), "\n")
z = -2.6661 
cat("臨界值 = ±", round(cv, 3), "\n")
臨界值 = ± 1.96 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.0077 
cat("決策:", ifelse(abs(z) > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 拒絕 H0

例題 9-10：開車時傳訊息

問題

調查發現今年有 29% 的駕駛人開車時會傳訊息，去年為 17%。每個樣本各含 1000 名駕駛人。在 α = 0.01 下，檢定此比例是否增加的主張。

步驟 1： H₀：p₁ = p₂    H₁：p₁ > p₂（主張）——右尾檢定

步驟 2： CV = +2.33

步驟 3： \bar{p} = \frac{290+170}{1000+1000} = \frac{460}{2000} = 0.23；\bar{q} = 0.77

z = \frac{0.29 - 0.17}{\sqrt{0.23(0.77)\left(\frac{1}{1000}+\frac{1}{1000}\right)}} = \frac{0.12}{\sqrt{0.0003542}} = \frac{0.12}{0.01882} \approx 6.38

步驟 4： 6.38 > 2.33 → 拒絕 H₀

步驟 5： 有足夠證據支持開車傳訊息的比例已增加的主張。

例題 9-10：解題步驟（R）

x1 <- 290; n1 <- 1000   # 今年
x2 <- 170; n2 <- 1000   # 去年

phat1 <- x1/n1; phat2 <- x2/n2
pbar  <- (x1 + x2)/(n1 + n2)
qbar  <- 1 - pbar

z     <- (phat1 - phat2) / sqrt(pbar * qbar * (1/n1 + 1/n2))
cv    <- qnorm(0.99)
p_val <- pnorm(z, lower.tail = FALSE)

cat("z =", round(z, 4), "\n")
z = 6.3761 
cat("臨界值 =", round(cv, 3), "\n")
臨界值 = 2.326 
cat("P 值 =", round(p_val, 6), "\n")
P 值 = 0 
cat("決策:", ifelse(z > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 拒絕 H0

p₁ − p₂ 的信賴區間

Note

(\hat{p}_1-\hat{p}_2) - z_{\alpha/2}\sqrt{\frac{\hat{p}_1\hat{q}_1}{n_1}+\frac{\hat{p}_2\hat{q}_2}{n_2}} < p_1-p_2 < (\hat{p}_1-\hat{p}_2) + z_{\alpha/2}\sqrt{\frac{\hat{p}_1\hat{q}_1}{n_1}+\frac{\hat{p}_2\hat{q}_2}{n_2}}

例題 9-11：疫苗接種率差異的 95% 信賴區間

問題

使用例題 9-9 的資料，求 p₁ − p₂ 的 95% 信賴區間。

解答： \hat{p}_1 = 0.353，\hat{p}_2 = 0.708；z_{0.025} = 1.96

\sqrt{\frac{(0.353)(0.647)}{34}+\frac{(0.708)(0.292)}{24}} = \sqrt{0.00671 + 0.00861} = \sqrt{0.01532} = 0.1238

-0.355 \pm 1.96(0.1238) = -0.355 \pm 0.243

\boxed{-0.602 < p_1 - p_2 < -0.118}

區間不包含 0，確認兩者存在顯著差異。

例題 9-11：解題步驟（R）

x1 <- 12; n1 <- 34
x2 <- 17; n2 <- 24

phat1 <- x1/n1; phat2 <- x2/n2
qhat1 <- 1 - phat1; qhat2 <- 1 - phat2
diff  <- phat1 - phat2
se    <- sqrt(phat1*qhat1/n1 + phat2*qhat2/n2)
moe   <- qnorm(0.975) * se

cat("95% CI: (", round(diff - moe, 3), ",", round(diff + moe, 3), ")\n")
95% CI: ( -0.598 , -0.113 )

第 9-5 節：兩個變異數差異的檢定

F 分配

Note

F 分配用於比較來自兩個獨立常態分配母體的變異數。

特性： - F 值恆 ≥ 0（變異數為非負值） - 分配呈正偏態 - 均值 ≈ 1 - 由兩個自由度參數決定曲線形狀：分子自由度（d.f.N.）與分母自由度（d.f.D.）

F 檢定公式

Note

F = \frac{s_1^2}{s_2^2}

其中 s_1^2 永遠是較大的變異數（放在分子）。

  • d.f.N. = n_1 - 1（較大變異數所來自的樣本）
  • d.f.D. = n_2 - 1

假設條件： 1. 兩個樣本均為隨機且獨立 2. 兩個母體均為常態分配 3. 雙尾檢定時，使用 \alpha/2 臨界值表（僅右尾）

F 檢定的重要規則

Important

  1. 永遠將較大的變異數放在分子
  2. 雙尾檢定時，α 除以 2，使用右尾臨界值
  3. 若給定的是標準差，需平方以求得變異數
  4. 若自由度不在表格中，使用下一個較小的自由度

例題 9-12：求臨界值（右尾檢定）

問題

求右尾 F 檢定的臨界值，其中 α = 0.05，d.f.N. = 15，d.f.D. = 21。

解答： 使用 α = 0.05 的表格。查 d.f.N. = 15（欄）與 d.f.D. = 21（列）。

F_{CV} = 2.18

例題 9-12：解題步驟（R）

# 右尾 F 檢定的臨界值
alpha  <- 0.05
dfN    <- 15
dfD    <- 21

cv <- qf(1 - alpha, dfN, dfD)
cat("臨界值（右尾，alpha=0.05）:", round(cv, 4), "\n")
臨界值（右尾，alpha=0.05）: 2.1757

例題 9-13：求臨界值（雙尾檢定）

問題

求雙尾 F 檢定的臨界值，其中 α = 0.05，分子變異數來自樣本數為 21 的樣本，分母變異數來自 n = 12 的樣本。

解答： 雙尾 → 使用 α/2 = 0.025 的表格。

d.f.N. = 21 − 1 = 20，d.f.D. = 12 − 1 = 11

F_{CV} = 3.23

例題 9-13：解題步驟（R）

alpha <- 0.05
n1    <- 21; n2 <- 12
dfN   <- n1 - 1; dfD <- n2 - 1

cv <- qf(1 - alpha/2, dfN, dfD)
cat("臨界值（雙尾，alpha=0.05）:", round(cv, 4), "\n")
臨界值（雙尾，alpha=0.05）: 3.2261 
cat("d.f.N. =", dfN, "，d.f.D. =", dfD, "\n")
d.f.N. = 20 ，d.f.D. = 11

例題 9-14：吸菸者的心率

問題

某研究者想確定吸菸者與非吸菸者的心率（次/分鐘）變異數是否不同。在 α = 0.05 下，檢定此主張。

吸菸者 非吸菸者
n 26 18
s^2 36 10

例題 9-14：解題步驟（數學）

步驟 1： H₀：σ₁² = σ₂²    H₁：σ₁² ≠ σ₂²（主張）——雙尾檢定

步驟 2： 使用 α/2 = 0.025 的表格。 d.f.N. = 26 − 1 = 25；d.f.D. = 18 − 1 = 17 → CV = 2.56（使用 d.f.N. = 24）

步驟 3： F = \frac{s_1^2}{s_2^2} = \frac{36}{10} = 3.6

步驟 4： 3.6 > 2.56 → 拒絕 H₀

步驟 5： 有足夠證據支持吸菸者與非吸菸者心率變異數不同的主張。

例題 9-14：解題步驟（R）

s1_sq <- 36; n1 <- 26
s2_sq <- 10; n2 <- 18

F_stat <- s1_sq / s2_sq
dfN    <- n1 - 1; dfD <- n2 - 1
cv     <- qf(0.975, dfN, dfD)
p_val  <- 2 * pf(F_stat, dfN, dfD, lower.tail = FALSE)

cat("F =", round(F_stat, 4), "\n")
F = 3.6 
cat("d.f.N. =", dfN, "，d.f.D. =", dfD, "\n")
d.f.N. = 25 ，d.f.D. = 17 
cat("臨界值（雙尾）=", round(cv, 4), "\n")
臨界值（雙尾）= 2.5484 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.0084 
cat("決策:", ifelse(F_stat > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 拒絕 H0

例題 9-15：就診等待時間

問題

第一家醫院急診等待時間的標準差為 32 分鐘（n = 16）；第二家醫院為 28 分鐘（n = 18）。在 α = 0.01 下，檢定第一家醫院變異是否較大的主張。

步驟 1： H₀：σ₁² = σ₂²    H₁：σ₁² > σ₂²（主張）——右尾檢定

步驟 2： d.f.N. = 15，d.f.D. = 17 → CV = 3.31

步驟 3： F = \frac{32^2}{28^2} = \frac{1024}{784} \approx 1.306

步驟 4： 1.306 < 3.31 → 不拒絕 H₀

步驟 5： 沒有足夠證據支持第一家醫院等待時間變異較大的主張。

例題 9-15：解題步驟（R）

s1 <- 32; n1 <- 16
s2 <- 28; n2 <- 18

F_stat <- s1^2 / s2^2
dfN    <- n1 - 1; dfD <- n2 - 1
cv     <- qf(0.99, dfN, dfD)
p_val  <- pf(F_stat, dfN, dfD, lower.tail = FALSE)

cat("F =", round(F_stat, 4), "\n")
F = 1.3061 
cat("臨界值 =", round(cv, 4), "\n")
臨界值 = 3.3117 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.296 
cat("決策:", ifelse(F_stat > cv, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 不拒絕 H0

例題 9-16：機場旅客人數（P 值法）

問題

某執行長假設美國機場年旅客人數的變異大於外國機場。在 α = 0.10 下，使用 P 值法檢定此主張。

美國（百萬人）：36.8、72.4、60.5、73.5、61.2、40.1 外國（百萬人）：60.7、42.7、51.2、38.6

例題 9-16：解題步驟（數學）

步驟 1： H₀：σ₁² = σ₂²    H₁：σ₁² > σ₂²（主張）——右尾檢定

步驟 2： 計算變異數： s_1^2 = 246.38 \quad s_2^2 = 95.87

步驟 3： F = \frac{246.38}{95.87} \approx 2.57

d.f.N. = 5，d.f.D. = 3

由 F 分配表，α = 0.10：F = 5.31。由於 2.57 < 5.31，P 值 > 0.10（實際 P ≈ 0.234）

步驟 4： 不拒絕 H₀

步驟 5： 沒有足夠證據支持美國機場旅客人數變異較大的主張。

例題 9-16：解題步驟（R）

american <- c(36.8, 72.4, 60.5, 73.5, 61.2, 40.1)
foreign  <- c(60.7, 42.7, 51.2, 38.6)

s1_sq <- var(american)
s2_sq <- var(foreign)
F_stat <- s1_sq / s2_sq
dfN    <- length(american) - 1
dfD    <- length(foreign) - 1
p_val  <- pf(F_stat, dfN, dfD, lower.tail = FALSE)

cat("s1^2 =", round(s1_sq, 2), " s2^2 =", round(s2_sq, 2), "\n")
s1^2 = 246.38  s2^2 = 95.87 
cat("F =", round(F_stat, 4), "\n")
F = 2.5699 
cat("d.f.N. =", dfN, "，d.f.D. =", dfD, "\n")
d.f.N. = 5 ，d.f.D. = 3 
cat("P 值 =", round(p_val, 4), "\n")
P 值 = 0.2336 
cat("決策:", ifelse(p_val < 0.10, "拒絕 H0", "不拒絕 H0"), "\n")
決策: 不拒絕 H0

第 9 章摘要

情境 檢定 統計量
兩均值，σ 已知，獨立 z 檢定 z = \frac{\bar{X}_1-\bar{X}_2}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}
兩均值，σ 未知，獨立 t 檢定 t = \frac{\bar{X}_1-\bar{X}_2}{\sqrt{s_1^2/n_1+s_2^2/n_2}}，自由度 = min(n₁−1, n₂−1)
兩均值，相依樣本 配對 t 檢定 t = \frac{\bar{D}}{s_D/\sqrt{n}}，自由度 = n−1
兩比例 z 檢定 z = \frac{\hat{p}_1-\hat{p}_2}{\sqrt{\bar{p}\bar{q}(1/n_1+1/n_2)}}
兩變異數 F 檢定 F = s_1^2/s_2^2（較大者為分子）
